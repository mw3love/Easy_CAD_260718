# Magic Board 웹 칠판

데스크톱 Magic Board(`.ecad`)를 브라우저에서 여는 칠판. 계획: `docs/EasyCAD_계획.md` §8 항목61.

## 감시 PC에서 켜기 (회사 안 다른 PC는 크롬으로 접속)

처음 한 번(Node 24·Python 3 필요):

```
git pull
cd web
npm install
npm run build
```

켜기(리포 맨 위 폴더에서):

```
python web/server.py
```

- 다른 PC 크롬에서 `http://<감시 PC 주소>:5191`. 칠판은 주소 끝 `?board=이름`으로 나뉜다.
- 저장 폴더: `%APPDATA%\EasyCAD\web_boards\<이름>.ecad` (데스크톱과 같은 형식, 바로 앞 저장본은 `<이름>.prev.ecad`). 바꾸려면 `--data 폴더`.
- **기본 = 비밀번호 없음 · 칠판 주소가 곧 열쇠**(2026-10-27 사용자 — Excalidraw처럼): `/`로 처음 들어오면 짐작할 수 없는 새 주소(`?board=t37a3gc8`, 이름을 정하면 `송신소점검-t37a3gc8`)의
  빈 칠판이 열리고, 다시 오면 마지막 칠판. 칠판 목록은 「내 칠판 — 이 브라우저」(만들거나 열어 본 것)뿐이고 서버 전체 목록(`/api/boards`)은 숨긴다.
  남에게 줄 땐 「공유」의 주소를 보낸다 — 받은 사람은 처음 한 번 이름만 적고 같이 고친다. 주소가 퍼지면 누구나 고칠 수 있다(옛 이름 `main`처럼 짧은 주소는 짐작하기 쉬움).
- 비밀번호를 걸려면(회사 배포 등): `python web/server.py --password 비번`(또는 환경 변수 `MB_PASSWORD`, 또는 저장 폴더의 `edit_password.txt`) — 들어올 때 비밀번호 + 이름을 묻고,
  칠판 이름은 정한 그대로, 「이 서버의 칠판」 목록이 보인다. 비밀번호를 바꾸면 모두 다시 들어와야 한다.
- 팀별 칠판(§8 항목67): 저장 폴더에 `teams.json`을 두면 팀마다 비밀번호·칠판이 따로다(서버를 안 꺼도 바로 반영).
  ```json
  [{"name": "A팀", "password": "에이비번", "boards": ["A회의"]},
   {"name": "B팀", "password": "비비번", "boards": []}]
  ```
  팀 비밀번호로 들어오면 그 팀 칠판만 보이고·열리고, 새로 만든 칠판은 처음 저장할 때 그 팀 `boards`에 저절로 더해진다.
  **크레딧은 사람마다 「🔑 내 키」로 나눈다**(2026-10-27 사용자 결정 — KAIROS 키는 직원 한 사람마다 나옴). 각자 대화창 「🔑」에 자기 키를 넣으면 그 브라우저에서 묻는 것만
  그 사람 크레딧에서 나간다(같은 칠판을 같이 봐도 — 대화 기록은 칠판마다 하나라 같이 보이고, 크레딧은 물은 사람 것). 안 넣은 사람은 서버 키.
  (선택) 팀 줄의 `"key"` = 그 팀 전체가 함께 쓰는 키 — 팀원 한 사람의 개인 키를 팀이 나눠 쓰게 되므로 회사 규정 확인 뒤에만. 다른 계정 키면 `"base"`(그 계정 주소 — jbnu는 회사 주소로 401, 실측)도.
  위의 공용 비밀번호는 **관리자**(모든 칠판, 팀 없는 옛 칠판도). 파일이 깨지면 팀 로그인은 막히고 관리자만 들어온다(서버 창에 알림).
  초대 링크로 들어온 사람은 그 칠판 팀의 열쇠를 받는다(그 팀 다른 칠판도 열림). `teams.json`을 지우면 예전처럼 공용 비밀번호 하나.
- 게시: 칠판 상단 「🔗 공유」 → 「게시하기」 = 로그인 없이 보기·발표만 되는 링크(`/?view=…`). 「새 링크로 바꾸기」 = 옛 링크 막힘, 「게시 끄기」 = 막힘.
- 여럿이 동시에 고쳐도 서로 다른 도형이면 둘 다 남는다(같은 도형은 나중 것이 이김). 다른 사람 변경은 2초쯤 뒤에 보인다.
- ⚠ 사내망 `http`라 비밀번호가 암호화 없이 오간다 — 회사 보안 확인 전엔 `--host 127.0.0.1`(이 PC에서만).
- 코드를 고친 뒤엔 `npm run build`를 다시 하고 서버를 다시 켠다.
- 오른쪽 KAIROS 대화창은 이 서버가 게이트웨이를 대신 부른다 — 서버 PC에 `openai`·`httpx`(데스크톱 앱과 같은 것)와 키 파일
  `~/.claude/.secrets/easycad-gateway.key`가 있어야 한다(키는 브라우저로 안 간다). 대화 기록은 저장 폴더의 `<이름>.chat.json`.
  ⚠ 비밀번호가 없으면 칠판 주소를 아는 누구나 서버 키(내 크레딧)로 물을 수 있다(게시 링크로는 못 씀). 각자 키로만 묻게 하려면 `--no-server-key`(또는 환경 변수 `MB_SERVER_KEY=0`) —
  「🔑 내 키」가 없는 사람이 물으면 대화창이 키 칸을 연다. 내 키는 그 브라우저에 남아서 한 번만 넣으면 된다.

## 개발

```
cd web
npm run dev          # http://localhost:5190 — 저장은 python web/server.py(5191)로 넘김, 서버가 없으면 이 브라우저에만
npm test             # 순수 함수 시험
npm run e2e          # 화면 자동 시험 — 빌드 후 깔린 크롬으로 매일 쓰는 흐름(e2e/flow1~40, 164개)을 돌림, 약 5분
```

화면 시험(2026-10-19 다잡기)은 시험용 서버를 따로 띄운다 — 문 5291·데이터 `web/.e2e-data`(시험 전에 비움, git 밖). 켜 둔 진짜 서버(5191)·칠판과 섞이지 않는다.
KAIROS는 가짜 답으로 바꿔 끼워 크레딧을 안 쓴다. 글쇠를 바꾸면 `src/next/keys.js`(도움말 F1이 보여 주는 표)와 `e2e/flow9-keys.spec.js`를 같이 고친다.
실패하면 `web/test-results/`의 trace를 `npx playwright show-trace <경로>`로 본다.

칠판은 직접 만든 것(`src/next/`) — 2026-10-18 tldraw에서 갈아탐(§8 항목61 5단계). 문서는 `.ecad` 그대로, 서버 저장은 `/api/doc/<이름>`.
옛 주소 `next.html?board=…`는 `/`로 넘어간다(즐겨찾기용). 글 편집은 TipTap 3.32.0(MIT), 부품은 `package.json`에 모두 버전 고정.
