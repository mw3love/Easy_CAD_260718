# 웹 칠판 화면 규칙

웹 칠판(`web/src/next/`)의 단추·메뉴·확인 창·이름 고치기를 판마다 다르게 만들지 않기 위한 규칙이다.
2026-10-28 사용자 판정(판정 페이지 https://claude.ai/artifact/TtnHM5bYNMnj1A3nd16Myc, 취향 기록 `~/.claude/design-system/projects/easy-cad.md` 「웹 왼쪽 판 규칙 1라운드」)으로 정했고, 2026-11-02 코드에 적용했다.
새 판·새 메뉴를 만들 때는 이 문서를 먼저 보고 공용 부품을 쓴다.

## 공용 부품

- **색**: 코랄은 CSS 변수 `--mb-accent`(`web/index.html`) 하나다. 화면 코드에서는 `var(--mb-accent)`로 쓴다.
  예외는 SVG 그리기 속성(`fill=`·`stroke=`)이다 — 거기엔 CSS 변수가 안 먹으니 `#da7756` 그대로 둔다(`render.jsx`·`skeleton.jsx`·레이어 연필 아이콘). 칠판에 저장되는 물건의 색(번호표 등)도 값 그대로다.
- **아이콘 포인트 파랑**(2026-11-08): 위 막대·왼쪽 판 아이콘의 채운 부분만 `--mb-icon-acc`(`web/index.html` `.mb-btn-icon`). 코랄과 달리 상태를 뜻하지 않는다 — 켜짐 표시는 그대로 코랄 바탕.
- **글자 색은 두 화면에서 4.5 이상**: 링크 = `var(--mb-link)`. 밝게/어둡게 값이 다른 이름표·상태 글은 `light-dark(밝은 화면, 어두운 화면)`로 쓴다(`chat.jsx` `KINDS`, 2026-11-09). 코랄 글자만 예외(사용자 결정).
- **글 칸 초점**: 글 칸은 `className="mb-field"` — 초점이면 테두리 파랑. **끌어서 폭 조절**은 `role="separator"` + `tabIndex={0}` + ← → 글쇠를 같이 단다.
- **빨간 글**: 오류·경고 글자는 `var(--mb-danger-ink)`(라이트·다크 따로 — 대비 4.5 이상). `ui.jsx` `DANGER`(#b9342f — 2026-11-10 #d44c47에서 진하게, 흰 글 5.84)는 흰 글을 얹는 단추 바탕용이다(2026-11-09). 빨강 값을 직접 쓰지 않는다.
- **초점 표시**: 단추가 `all: 'unset'`이어도 글쇠 초점 테두리는 `index.html`의 전역 `:focus-visible` 규칙이 그린다(파랑 `--mb-icon-acc`). 제 테두리를 직접 그리는 단추만 `data-own-ring`을 단다(확인 창). `outline: 'none'`으로 지우지 않는다(2026-11-09).
- **메뉴**: `ctxmenu.jsx`의 `ContextMenu`(칠판 위)·`FloatMenu`(판 위) 하나뿐이다. 바깥 누르기·Esc로 닫힌다.
  ⋯ 단추로 열 때는 `ui.jsx`의 `menuBelow(e)`로 자리를 잡는다 — 그 단추를 `anchor`로 기억해서, 같은 ⋯를 다시 누르면 닫힌다.
- **글 입력부**: 대화창·AI 칩 창·말풍선은 `composer.jsx` `Composer` 하나 — 글과 단추가 한 상자, 내용에 맞춰 늘어남, 오른쪽 아래 ↑ 보내기(2026-11-09). AI에게 말을 보내는 새 입력 칸도 이것을 쓴다.
- **확인 창·단추·마우스 올림**: `ui.jsx`의 `Confirm`·`btnPrimary`·`btnSecondary`·`btnHead`·`moreBtn`·`hoverBg`. `Confirm`은 `<dialog>`(showModal — 뒤 막힘·Tab은 창 안), 메뉴 항목에서 열면 `returnTo`에 메뉴를 연 단추를 준다. 새 큰 창도 `useModalDialog`로 같은 방식(`chat.jsx` `BigModal`). 작은 단추(⋯·▾)는 겉모양 그대로 `className="mb-hit"` + `position: 'relative'`(`--hit`로 넓힐 둘레)로 누르는 자리를 24px 이상(2026-11-09).

- **위 막대와 왼쪽 판**(2026-11-09 시안 C): 판이 열린 넓은 창에서는 위 막대 왼쪽이 판의 머리다 — 이름 칸 폭 = 판 폭, 도구는 판 끝선 오른쪽부터, 이름 밑 가로줄 없음(`main.jsx` `headed`). 도구가 들어갈 자리가 없으면 예전 배치. 위 막대에 버튼을 많이 더해 도구 줄이 길어지면 `TOOLS_ROOM`도 다시 잰다.

## 규칙

- **A1 코랄 채움 단추는 판마다 대표 행동 하나**다. 칠판 판 「＋ 새 칠판」, 프레임 판 「▶ 발표」. 그 밖의 단추는 회색 테두리다(프레임 줄 ▶도 회색).
- **B1 「＋ 새 폴더」·「＋ 새 레이어」는 머리줄 오른쪽 작은 단추**다(`btnHead`).
- **① 새로 만들기는 「＋ 새 ○○」**라고 쓴다.
- **A2 대화창 카드(질문지·계획 카드)**(2026-11-07 대화창 bakeoff): 고른 보기 = 회색 채움 ✓(`--mb-pick`), 코랄 채움은 일을 시작하는 단추(「계획 짜기」·「이대로 만들기」)만 — 고른 것과 단추가 같은 코랄 테두리라 헷갈렸음. 질문은 Claude Code식 질문 탭(`deepchat.jsx` `DeepAsk`), 설명 문구 없이.
- **② 같은 일은 같은 말**로 쓴다. 지우기(「삭제」 아님)·이름 바꾸기(「이름 변경」 아님)·내려받기·불러오기. 창이 뜨는 메뉴 항목은 끝에 「…」을 붙인다(「지우기…」·「불러오기…」·「이 프레임 내보내기…」).
- **③ 마우스 올림은 회색 바탕**(`var(--mb-group)`)이다. 코랄 바탕은 켜짐·지금 칠판 같은 뜻 있는 상태에만 쓴다. 칸 폭을 끄는 경계선의 코랄은 「끌 수 있음」 표시라 그대로 둔다.
- **④ ⋯ 단추**: 줄에 붙은 ⋯는 마우스를 올렸을 때만 보인다(글쇠로 그 줄에 왔을 때도 — 줄 `mb-row`·⋯ `mb-more` 클래스, 2026-11-09). 끌어서 순서 바꾸기엔 글쇠·메뉴 길도 둔다(칠판 판 = Alt+↑↓·「위로/아래로 옮기기」). 머리줄의 ⋯는 늘 보이고 테두리가 없다. 우클릭하면 ⋯와 같은 메뉴가 뜬다.
- **⑤ 메뉴는 한 부품**(위 「공용 부품」)이다. 칠판 판 「＋ 새 칠판 ▾」 메뉴만 칠판 코드 입력 칸을 품어서 따로 그리지만, 모양·마우스 올림은 같다.
- **⑥ 되돌릴 수 없는 지우기만 확인 창**을 띄운다. Enter = 확인, Esc·바깥 = 취소. 빈 폴더처럼 잃을 것이 없으면 바로 지우고, 레이어 지우기(도형은 「기본」으로 남음)·프레임만 지우기(Ctrl+Z 됨)도 묻지 않는다.
- **⑦ 이름 고치기**: Enter·바깥 누르기 = 저장, Esc = 취소(처음 이름으로).
- **⑧ 예시 되돌리기는 따로 보이는 단추**다(메뉴 안에 숨기지 않음).

## 휴대폰(2026-11-06 아이폰 실사용 + bakeoff 2라운드)

- **H1 입구를 나눈다**: 위 막대 = [칠판 이름 ▾] [사람 수] [공유] [밝기]. 한 판에 칠판 고르기·공유·만들기를 다 담지 않는다(「너무 많음」으로 탈락).
- **H2 누른 자리 밑 작은 메뉴**(`main.jsx` `PhonePop`) — 아래에서 올라오는 큰 판보다 이것(「손으로 누른 곳 근처에 떠서 좋음」).
- **H3 설명 글 없이 아이콘 + 짧은 글자**: 아이콘은 앱 손그림(`icons.json`) + 없으면 같은 선 굵기 1.6으로(`PICON`). 정해진 값(칠판 코드·주소)은 그대로 보이고 옆에 복사·QR·보내기 아이콘.
- **H4 누르는 곳은 44px**: 메뉴 줄도(`ContextMenu touch`) — PC 메뉴(최소 폭 190·줄 28px)를 폰에 그대로 쓰지 않는다.
- **H5 코랄 채움 없음**: 폰은 큰 단추·강조 채움 없이 납작하게(회색 알약 `PILL`). 켜고 끄는 건 스위치.
- **H6 같은 기능은 PC와 같은 이름**: 「발표」(옛 「차례로」)·「보기 전용 링크」(옛 「게시」).
- **H7 덮개는 click에 닫는다**: 바깥 pointerdown에 닫으면 떼는 톡이 그 아래 단추를 누른다(`PhonePop`·`QrBig`, `docs/pitfalls.md`).

- **H8 마우스 올림은 마우스만**(2026-11-11): `hoverBg`·메뉴 줄 올림은 `pointerType === 'mouse'`일 때만 칠한다 — 손가락으로 누르면 회색이 남아 켜진 것처럼 보였음.
- **H9 손가락 기기 판별은 하나**: `(pointer: coarse)` + 짧은 변 700 미만 = 휴대폰(`ui.jsx` `isPhone`, `index.html` 첫 빈 틀도 같은 식). 태블릿(짧은 변 700 이상)은 PC 화면이되 `@media (pointer:coarse)`로 `.mb-hit` 누르는 자리만 넓힌다 — 넓힌 자리가 옆 단추를 덮으면 그 단추만 `--hit-c`로 줄인다.
- **H10 휴대폰도 칠판 안에서 연다**: 문서 카드 톡 = 앱 안 문서 큰 창 「보기·인쇄만」(새 탭 아님), 붙인 뒤 되돌리기 = 답 카드 「칠판에 붙임 ✓」 옆(시간 제한 없음).

시험: `web/e2e/flow40-phone.spec.js`·`flow76-phone.spec.js`.

## 화면 검사 0~9단계에서 정한 것(2026-11-10~11)

웹 칠판 전체를 `better-interface` 6분야로 단계별로 검사하고 고치며 정한 것이다. 경위는 `docs/history/2026-11.md` 「화면 검사 N단계」 절.

- **C1 공용 변수**(`web/index.html`): 켜짐 = `--mb-on` 바탕 + `--mb-on-ring` 테두리 + 검정 글(위 막대·꾸밈 줄·속성 카드·레일·내보내기·발표 막대 모두 — 코랄 채움 아님). 글 칸·두 번째 단추 테두리 = `--mb-ctl`(구분선 `--mb-line`은 선만). 그림자 = `--mb-shadow`·`--mb-shadow-lg` 둘. 묶음 안 마우스 올림 = `--mb-group-hover`, 고른 줄 = `--mb-row-on`, 내 질문 바탕 = `--mb-seg`. 따로 테마가 있는 화면(발표 D)은 뿌리에 `data-mb-theme`를 달아 같은 변수를 받는다(값을 복사하지 않음).
- **C2 선택은 파랑**: 밝게 #3b82f6·어둡게 #89b4fa(칠판 `Editor` `BLUE`). 메모·문서 종이처럼 **어두운 화면에서도 늘 흰 바탕**이면 밝게 값 하나(어둡게 값은 흰 바탕 위 2.11). 틀(iframe)·SVG 안은 변수·`light-dark()`가 안 먹으니 값을 넘긴다.
- **C3 SVG 글 색은 값으로, 4.5 이상**: 칠판 위 카드 보조 글 회색 #63636b, 초록 알약 #15803d.
- **C4 `mb-hit`에는 `position: relative`**: 없으면 `::after`가 창 전체를 덮어 다른 단추가 안 눌린다.
- **C5 메뉴 글쇠**: `role=menu`/`menuitem`, 열면 첫 줄로 초점, ↑↓ Home End, → ← 하위 목록, Esc = 연 단추로, Tab = 닫힘. 고른 것이 있으면 Shift+F10·메뉴 키 = 우클릭 메뉴. 고르는 목록(줄 종류·명령 검색·찾기)은 `listbox`/`option` + `aria-activedescendant`. 메뉴 줄 마우스 올림은 `onMouseMove`(메뉴가 가만히 있는 마우스 밑에 뜨면 엉뚱한 줄이 골라짐).
- **C6 창과 판**: 큰 창 = `useModalDialog`(열면 안으로 초점·Tab은 안에서·닫으면 연 자리로 — 연 자리가 칠판 대기 편집기면 칠판에 맡김). 막대에서 여는 작은 판 = `fitPop`(`main.jsx` — 화면 안으로 밀고 넘치면 판 안 굴림, Esc = 연 단추로). 640×360(1280 창 200% 확대)에서 단추 줄이 화면 안에 있는지 본다.
- **C7 오류 글은 쉬운 말 + 다음 할 일**: `chatFormat.aiError` 하나(연결 끊김·429·크레딧 부족), `var(--mb-danger-ink)`, `role="alert"`, 그 자리에 「다시 보내기」. 서버 원문만 내보이지 않는다.
- **C8 되돌리는 유일한 길은 시간으로 사라지지 않는다**: 판서 지움 띠 = 다음 편집이나 ✕까지, 서버 끊김 = 남는 띠, 붙인 뒤 되돌리기 = 답 카드 옆. 알림 칸(`role=status`)은 미리 두고 글만 바꾼다.
- **C9 크레딧이 많이 드는 일은 확인 창**(「이 장 움직이게」·「잘린 곳 고치기」 등 — 약 N크레딧 + 남은 크레딧). 실패해서 되풀이될 일(🔊)은 실패하면 끈다.
- **C10 글자**: 단축키 글은 `keyLabel()`(맥 ⌘ ⌥ ⇧), 바뀌는 숫자는 `tabular-nums`, 한국어 말은 `wordBreak: 'keep-all'` + `overflowWrap: 'anywhere'`, 사용자에게 속 이름(「b2」 등)을 보이지 않는다(블록 이름 = 첫 낱말).
- **C11 움직임**: 큰 화면 이동(발표 장 넘김)·스위치 움직임은 `prefers-reduced-motion`이면 끈다. 로딩 표시(스켈레톤·스피너)는 남긴다. 칠판 위 움직이는 카드는 누를 때만 돈다(발표·내보내기 경로는 그대로).
- **C12 진행 방식**: 겉모양이 크게 바뀌는 고침은 전후 비교 페이지를 보여 주고 고른 뒤 한다(0단계 B 7건). 겉모양이 거의 안 바뀌는 접근성·글 고침은 바로.
