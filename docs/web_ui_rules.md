# 웹 칠판 화면 규칙

웹 칠판(`web/src/next/`)의 단추·메뉴·확인 창·이름 고치기를 판마다 다르게 만들지 않기 위한 규칙이다.
2026-10-28 사용자 판정(판정 페이지 https://claude.ai/artifact/TtnHM5bYNMnj1A3nd16Myc, 취향 기록 `~/.claude/design-system/projects/easy-cad.md` 「웹 왼쪽 판 규칙 1라운드」)으로 정했고, 2026-11-02 코드에 적용했다.
새 판·새 메뉴를 만들 때는 이 문서를 먼저 보고 공용 부품을 쓴다.

## 공용 부품

- **색**: 코랄은 CSS 변수 `--mb-accent`(`web/index.html`) 하나다. 화면 코드에서는 `var(--mb-accent)`로 쓴다.
  예외는 SVG 그리기 속성(`fill=`·`stroke=`)이다 — 거기엔 CSS 변수가 안 먹으니 `#da7756` 그대로 둔다(`render.jsx`·`skeleton.jsx`·레이어 연필 아이콘). 칠판에 저장되는 물건의 색(번호표 등)도 값 그대로다.
- **아이콘 포인트 파랑**(2026-11-08): 위 막대·왼쪽 판 아이콘의 채운 부분만 `--mb-icon-acc`(`web/index.html` `.mb-btn-icon`). 코랄과 달리 상태를 뜻하지 않는다 — 켜짐 표시는 그대로 코랄 바탕.
- **빨간 글**: 오류·경고 글자는 `var(--mb-danger-ink)`(라이트·다크 따로 — 대비 4.5 이상). `ui.jsx` `DANGER`(#d44c47)는 흰 글을 얹는 단추 바탕용이다(2026-11-09).
- **초점 표시**: 단추가 `all: 'unset'`이어도 글쇠 초점 테두리는 `index.html`의 전역 `:focus-visible` 규칙이 그린다(파랑 `--mb-icon-acc`). 제 테두리를 직접 그리는 단추만 `data-own-ring`을 단다(확인 창). `outline: 'none'`으로 지우지 않는다(2026-11-09).
- **메뉴**: `ctxmenu.jsx`의 `ContextMenu`(칠판 위)·`FloatMenu`(판 위) 하나뿐이다. 바깥 누르기·Esc로 닫힌다.
  ⋯ 단추로 열 때는 `ui.jsx`의 `menuBelow(e)`로 자리를 잡는다 — 그 단추를 `anchor`로 기억해서, 같은 ⋯를 다시 누르면 닫힌다.
- **확인 창·단추·마우스 올림**: `ui.jsx`의 `Confirm`·`btnPrimary`·`btnSecondary`·`btnHead`·`moreBtn`·`hoverBg`. `Confirm`은 `<dialog>`(showModal — 뒤 막힘·Tab은 창 안), 메뉴 항목에서 열면 `returnTo`에 메뉴를 연 단추를 준다. 작은 단추(⋯·▾)는 겉모양 그대로 `className="mb-hit"` + `position: 'relative'`(`--hit`로 넓힐 둘레)로 누르는 자리를 24px 이상(2026-11-09).

## 규칙

- **A1 코랄 채움 단추는 판마다 대표 행동 하나**다. 칠판 판 「＋ 새 칠판」, 프레임 판 「▶ 발표」. 그 밖의 단추는 회색 테두리다(프레임 줄 ▶도 회색).
- **B1 「＋ 새 폴더」·「＋ 새 레이어」는 머리줄 오른쪽 작은 단추**다(`btnHead`).
- **① 새로 만들기는 「＋ 새 ○○」**라고 쓴다.
- **A2 대화창 카드(질문지·계획 카드)**(2026-11-07 대화창 bakeoff): 고른 보기 = 회색 채움 ✓(`--mb-pick`), 코랄 채움은 일을 시작하는 단추(「계획 짜기」·「이대로 만들기」)만 — 고른 것과 단추가 같은 코랄 테두리라 헷갈렸음. 질문은 Claude Code식 질문 탭(`deepchat.jsx` `DeepAsk`), 설명 문구 없이.
- **② 같은 일은 같은 말**로 쓴다. 지우기(「삭제」 아님)·이름 바꾸기(「이름 변경」 아님)·내려받기·불러오기. 창이 뜨는 메뉴 항목은 끝에 「…」을 붙인다(「지우기…」·「불러오기…」·「이 프레임 내보내기…」).
- **③ 마우스 올림은 회색 바탕**(`var(--mb-group)`)이다. 코랄 바탕은 켜짐·지금 칠판 같은 뜻 있는 상태에만 쓴다. 칸 폭을 끄는 경계선의 코랄은 「끌 수 있음」 표시라 그대로 둔다.
- **④ ⋯ 단추**: 줄에 붙은 ⋯는 마우스를 올렸을 때만 보인다(글쇠로 그 줄에 왔을 때도 — 줄 `mb-row`·⋯ `mb-more` 클래스, 2026-11-09). 끌어서 순서 바꾸기엔 글쇠·메뉴 길도 둔다(칠판 판 = Alt+↑↓·「위로/아래로 옮기기」). 머리줄의 ⋯는 늘 보이고 테두리가 없다. 우클릭하면 ⋯와 같은 메뉴가 뜬다.
- **⑤ 메뉴는 한 부품**(위 「공용 부품」)이다. 칠판 판 「＋ 새 칠판 ▾」 메뉴만 칠판 코드 입력 칸을 품어서 따로 그리지만, 모양·마우스 올림은 같다.
- **⑥ 되돌릴 수 없는 지우기만 확인 창**을 띄운다. Enter = 확인, Esc·바깥 = 취소. 빈 폴더처럼 잃을 것이 없으면 바로 지우고, 레이어 지우기(도형은 「기본」으로 남음)·프레임만 지우기(Ctrl+Z 됨)도 묻지 않는다.
- **⑦ 이름 고치기**: Enter·바깥 누르기 = 저장, Esc = 취소(처음 이름으로).
- **⑧ 예시 되돌리기는 따로 보이는 단추**다(메뉴 안에 숨기지 않음).

## 휴대폰(2026-11-06 아이폰 실사용 + bakeoff 2라운드)

- **H1 입구를 나눈다**: 위 막대 = [칠판 이름 ▾] [사람 수] [공유] [밝기]. 한 판에 칠판 고르기·공유·만들기를 다 담지 않는다(「너무 많음」으로 탈락).
- **H2 누른 자리 밑 작은 메뉴**(`main.jsx` `PhonePop`) — 아래에서 올라오는 큰 판보다 이것(「손으로 누른 곳 근처에 떠서 좋음」).
- **H3 설명 글 없이 아이콘 + 짧은 글자**: 아이콘은 앱 손그림(`icons.json`) + 없으면 같은 선 굵기 1.6으로(`PICON`). 정해진 값(칠판 코드·주소)은 그대로 보이고 옆에 복사·QR·보내기 아이콘.
- **H4 누르는 곳은 44px**: 메뉴 줄도(`ContextMenu touch`) — PC 메뉴(최소 폭 190·줄 28px)를 폰에 그대로 쓰지 않는다.
- **H5 코랄 채움 없음**: 폰은 큰 단추·강조 채움 없이 납작하게(회색 알약 `PILL`). 켜고 끄는 건 스위치.
- **H6 같은 기능은 PC와 같은 이름**: 「발표」(옛 「차례로」)·「보기 전용 링크」(옛 「게시」).
- **H7 덮개는 click에 닫는다**: 바깥 pointerdown에 닫으면 떼는 톡이 그 아래 단추를 누른다(`PhonePop`·`QrBig`, `docs/pitfalls.md`).
