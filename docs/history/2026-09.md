# Easy CAD — 진행 기록 (2026년 9월)

> 함정(⚠)만 골라 정리한 요약은 `docs/pitfalls.md` 참조. 최신 지침은 `CLAUDE.md`.
> 이전 기록: `docs/history/2026-08b.md`(08-15~08-31).

## UI 원칙 점검(design-bakeoff 0-b) — 테마 전환 버그 2건 + 원칙 위반 3건 수정 (2026-09-25)

`design-bakeoff` 스킬로 "디자인·UI·UX 개선할 곳" 검토를 요청받아, 후보 비교 전에 객관적
원칙 8개(그리드·그룹핑·위계·터치타겟·아이콘 일관성·대비·전경배경·상태표시)를 실제 창
스크린샷(1600×950·1280×720, 다크/라이트)에 대조했다. 정답이 있는 항목 5개를 고쳤다.

1. **색 견본 소실** — 도형을 선택한 채 테마를 바꾸면 속성 패널 "색"의 견본이 사라지고
   `#1f6feb` 글자만 남았다. `_apply_theme`가 `_pf_color`·`_pf_fill`에도 버튼 공용 QSS
   (`btn_qss`)를 덮어써 `_swatch_css`가 지워진 것 — 두 견본을 그 목록에서 뺐다.
2. **레이어 패널 접기 화살표만 옛 색** — 2026-08-19 레이어 패널 분리 때
   `_refresh_collapse_color` 재도색 목록에 `_layers_panel`이 안 들어갔다. 추가.
3. **보조 글씨 대비** — 폴더명·안내문·색 값이 고정 `#888`·11px(라이트 배경 대비 3.15:1).
   팔레트 `PlaceholderText`를 따르게 하고(다크 `#8a98a8` 5.7:1 / 라이트 `#626c78` 4.7:1),
   12px로 올렸다. ⚠ 처음엔 크기·여백을 스타일시트로 줬더니 라벨이 앱 팔레트 대신 Qt 기본
   PlaceholderText(흰색 α128)를 받아 라이트에서 오히려 더 안 보였다 — 크기는 `QFont.
   setPixelSize`, 여백은 `setContentsMargins`로 바꿔 해결(pitfalls 렌더링 항목).
4. **레이어 표시/잠금 아이콘** — 컬러 이모지(👁🚫🔒🔓) → Phosphor 듀오톤 SVG
   (`layer_visible/hidden/locked/unlocked.svg`)를 기존 `_svg_icon` 재칠 경로로 중립색 렌더.
   테마 전환 시 행 재구성 없이 `_refresh_layer_icons`로 아이콘만 다시 칠한다.
5. **탭 닫기 버튼** — Fusion 기본 빨간 네모 ✗가 "강조색은 의미 있는 상태에만" 확정 취향과
   충돌. 탭바에만 `QTabBar::close-button` QSS로 회색 ✗(`tab_close.svg`, Phosphor regular x,
   `#7d8794` — 두 테마 모두 3:1 이상) + 호버 중립 틴트.

Phosphor 아이콘은 MIT — `easycad/resources/icons/LICENSE-phosphor.txt`에 출처·라이선스.
회귀 테스트 4종을 `tests/test_part6_grid_minimap_layers.py` 끝에 추가.

Rejected: 탭 닫기 버튼을 탭마다 커스텀 QToolButton으로 교체 | 새 탭 생성 경로 2곳 +
  이동 가능한 탭의 인덱스 역추적까지 필요해 QSS 한 줄보다 복잡
Rejected: 보조 글씨 색을 테마별 전역 변수 + `_apply_theme`에서 라벨 재도색 | 폴더 라벨은
  심볼 섹션 재구성마다 새로 만들어져 추적 목록이 필요 — 팔레트 역할은 자동 전파됨
Constraint: 팔레트 `PlaceholderText` 변경은 입력칸 placeholder 글씨에도 같이 적용된다
  (더 진해짐 — 같은 대비 원칙이라 의도된 부수효과)
Confidence: high
Not-tested: 탭 닫기 버튼 호버의 실제 마우스 체감(스크린샷은 평상시 상태만 확인)

남은 주관적 후보(베이크오프 대상, 미착수): 스냅·격자 토글 "텍스트+체크마크"(2026-08-02
확정 후 미구현), 메뉴 전용 QPainter 아이콘 8종 스타일 통일, '내 심볼' 썸네일 옅음.

## 보기 토글 「체크박스+글자」 베이크오프 + 코드 반영 (2026-09-25)

2026-08-02 버튼 1라운드의 "토글 = 텍스트 라벨+체크마크" 결정이 아이콘 전용 `QToolButton`인
채로 미구현이던 것을, `design-bakeoff` 라이브 하네스(실행 중인 앱 툴바에 후보를 런타임으로
바꿔 끼움, 원본 무수정)로 실폭 비교해 확정하고 반영했다. 범위는 상단바 보기 묶음 4종(스냅·
직교·격자·정렬) — 스냅·격자만 바꾸면 한 묶음 안에서 모양이 섞여서.

| 후보 | 묶음 폭(기준 127px) | 툴바 필요폭(기본 창 1200px) | 결과 |
|---|---|---|---|
| A 체크박스+글자(원 아이콘 뺌) | 291 | 1184 — 들어감 | **채택** |
| B M3 필터칩(꺼짐=원 아이콘 / 켜짐=✓) | 311 | 1204 — 넘침 | 탈락 |
| C 체크박스+원 아이콘+글자 | 375 | 1268 — 넘침 | 탈락 |

넘치면 오른쪽 끝의 테마·도움말이 툴바 `»` 안으로 숨는다. 결정 근거는 폭(툴바 밀도).

**구현** (`host_ui.py`): 액션을 툴바에 그대로 싣지 않고 별도 `QToolButton`(텍스트 옆 아이콘)을
만들어 액션에 잇는다 — 액션 아이콘·텍스트는 보기(&V) 메뉴가 계속 쓰기 때문. 상태의 원본은
항상 액션이고, `QAction.changed`에 `_sync_view_toggle`을 걸어 체크·체크박스 아이콘·툴팁
(단축키 재할당 반영)을 따라가게 했다. 체크박스는 Phosphor `square`(regular)/`check-square`
(duotone)를 `check_off.svg`/`check_on.svg`로 넣고 기존 `_svg_icon` 중립색 재칠 경로로 렌더.
상태색은 기존 규칙 그대로 — 스냅·격자·정렬 checked는 옅은 틴트(35), 직교는
`#toolStrongCheck`(150+테두리). 직교가 이제 `widgetForAction`으로 안 잡혀 `_apply_theme`의
강조 대상 수집을 `_view_toggle_buttons`에서 찾도록 바꿨다. 좌우 여백은 툴바 QSS의
`QToolButton[viewToggle="true"]` 규칙으로만.

회귀 테스트 `test_view_toggles_are_checkbox_with_label`(`tests/test_part1_ui_arrows.py`).
하네스에서 밟은 함정(툴바 직속 `QToolButton`의 `setIconSize` 무시)은 pitfalls 렌더링 항목.

Rejected: 액션을 그대로 싣고 버튼의 아이콘만 덮어쓰기 | `setDefaultAction` 버튼은 액션이
  바뀔 때마다 아이콘을 액션 것으로 되돌려, 토글마다 다시 덮는 순서 의존 코드가 됨
Rejected: 필터칩(B)·아이콘+체크박스(C) | 기본 창 1200px에서 툴바가 넘침
Confidence: high
Not-tested: 실제 마우스 호버·눌림 체감(스크린샷은 평상시·켜짐 상태만)

## 옛 액션 아이콘 7종 → A2 손그림 SVG + '내 심볼' 썸네일 옅음 종결 (2026-09-25)

**1. 아이콘 7종** — `_act_icon`에 QPainter 선 글리프로 남아 있던 pdf·titleblock·table·image·
mermaid·zoom_100·zoom_fit은 원래 메뉴 전용이었지만, 2026-08-13부터 삽입 메뉴 전체가 툴바에도
나와 나머지 A2 손그림 SVG와 두 스타일이 섞여 보였다. `design-bakeoff` 라이브 하네스(액션
아이콘만 런타임 교체)로 P(Phosphor 듀오톤, 7/7 기성셋에 존재)와 H(A2 규칙 손그림: 외곽선 + 한
부분만 채움)를 비교해 **H 채택**(툴바 한 스타일 통일, P의 `corners-out`은 20px에서 옅은 면이
덩어리로 보임). `easycad/resources/icons/`에 7개 SVG를 넣고 `_SVG_ACT_ICON_NAMES`에 추가, 더
이상 안 타는 QPainter 분기 7개는 삭제(copy·check·stop·정렬/분배 글리프는 그대로).

**2. '내 심볼' 썸네일 옅음** — `CLAUDE.md` "미해결·보류"에 있던 항목. 현재 라이브러리 9개를
다크·라이트 실제 창으로 렌더해 보니 전부 기본 잉크(`#FFFFFF`)라 2026-08-26 도입한 기본
잉크 반전(`_ensure_symbol_thumb_current`)으로 두 테마 모두 기본도형 아이콘과 같은 진하기 —
**재현 안 됨, 사용자 확인으로 해결됨 처리**. 남은 가능성(비기본색 — 예: DXF 회색 — 심볼의
자동 밝기 보정)은 해당 심볼이 생기면 그때 다시 본다. 별개로 관찰된 것: `sf`·`fq`·`34`·`4`처럼
넓게 퍼지거나 떨어진 조각으로 된 심볼은 28px 칸에서 점 몇 개로 보인다(옅음이 아니라 크기 문제,
미착수).

Rejected: 7종을 Phosphor 듀오톤으로 | 툴바에 기성셋·손그림 두 출처가 섞이고, `corners-out`이
  20px에서 덩어리로 보임
Confidence: high
Not-tested: 새 아이콘의 메뉴(파일·삽입·보기) 안 표시 — 같은 QIcon이라 툴바와 같을 것으로 추정

## 계획서 비대화 정리 — 완료 항목 본문을 완료기록 파일로 (2026-09-25)

`docs/EasyCAD_계획.md`가 67,298자로 doc-sync 임계(40,000자)를 넘어, 2026-08-02 `CLAUDE.md` 분할과
같은 취지로 나눴다. 절별 크기를 재 보니 대부분이 완료 항목의 진행 경위(§8 「실제 도면 기반 신규
안건」 16k·「다각형」 12.6k·「다음 순서」 11.9k, Phase 6 M1~M5 5.3k)였다. 완료 항목 본문 925줄을
새 파일 `docs/EasyCAD_계획_완료기록.md`로 **원문 그대로** 옮기고, 계획서엔 같은 번호·제목·한 줄
요약·포인터만 남겼다(보류 항목 22·24·25·26, M2, 결정표, 남은 과제 줄, ⚠ 재시도 금지 같은 지침은
계획서에 유지). 결과 계획서 16,976자. 스크립트로 확인: 옮긴 줄 925개 전부 완료기록에 순서대로 존재,
남긴 줄 281개 변경 없음, 계획서의 포인터 16개가 전부 완료기록 절 제목과 일치. 코드·문서의
「§8 항목N」 참조는 번호를 그대로 뒀으므로 유효하다.

Rejected: history와 문단별로 대조해 겹치는 건 삭제(인계 원안) | 겹침이 문단마다 들쭉날쭉(예: "회랑
  사전필터"·"항목15 밀집"은 history에 0건)해 대조가 오래 걸리고 설계 근거가 빠질 위험
Confidence: high
Not-tested: 옮긴 본문 속 "위/아래 항목" 같은 상대 위치 표현 — 완료기록 머리말에 옛 계획서 기준이라고만 적음
