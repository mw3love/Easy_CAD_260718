## UI 원칙 점검(design-bakeoff 0-b) — 테마 전환 버그 2건 + 원칙 위반 3건 수정 (2026-09-25)

`design-bakeoff` 스킬로 "디자인·UI·UX 개선할 곳" 검토를 요청받아, 후보 비교 전에 객관적
원칙 8개(그리드·그룹핑·위계·터치타겟·아이콘 일관성·대비·전경배경·상태표시)를 실제 창
스크린샷(1600×950·1280×720, 다크/라이트)에 대조했다. 정답이 있는 항목 5개를 고쳤다.

1. **색 견본 소실** — 도형을 선택한 채 테마를 바꾸면 속성 패널 "색"의 견본이 사라지고
   `#1f6feb` 글자만 남았다. `_apply_theme`가 `_pf_color`·`_pf_fill`에도 버튼 공용 QSS
   (`btn_qss`)를 덮어써 `_swatch_css`가 지워진 것 — 두 견본을 그 목록에서 뺐다.
2. **레이어 패널 접기 화살표만 옛 색** — 2026-08-19 레이어 패널 분리 때
   `_refresh_collapse_color` 재도색 목록에 `_layers_panel`이 안 들어갔다. 추가.
3. **보조 글씨 대비** — 폴더명·안내문·색 값이 고정 `#888`·11px(라이트 배경 대비 3.15:1).
   팔레트 `PlaceholderText`를 따르게 하고(다크 `#8a98a8` 5.7:1 / 라이트 `#626c78` 4.7:1),
   12px로 올렸다. ⚠ 처음엔 크기·여백을 스타일시트로 줬더니 라벨이 앱 팔레트 대신 Qt 기본
   PlaceholderText(흰색 α128)를 받아 라이트에서 오히려 더 안 보였다 — 크기는 `QFont.
   setPixelSize`, 여백은 `setContentsMargins`로 바꿔 해결(pitfalls 렌더링 항목).
4. **레이어 표시/잠금 아이콘** — 컬러 이모지(👁🚫🔒🔓) → Phosphor 듀오톤 SVG
   (`layer_visible/hidden/locked/unlocked.svg`)를 기존 `_svg_icon` 재칠 경로로 중립색 렌더.
   테마 전환 시 행 재구성 없이 `_refresh_layer_icons`로 아이콘만 다시 칠한다.
5. **탭 닫기 버튼** — Fusion 기본 빨간 네모 ✗가 "강조색은 의미 있는 상태에만" 확정 취향과
   충돌. 탭바에만 `QTabBar::close-button` QSS로 회색 ✗(`tab_close.svg`, Phosphor regular x,
   `#7d8794` — 두 테마 모두 3:1 이상) + 호버 중립 틴트.

Phosphor 아이콘은 MIT — `easycad/resources/icons/LICENSE-phosphor.txt`에 출처·라이선스.
회귀 테스트 4종을 `tests/test_part6_grid_minimap_layers.py` 끝에 추가.

Rejected: 탭 닫기 버튼을 탭마다 커스텀 QToolButton으로 교체 | 새 탭 생성 경로 2곳 +
  이동 가능한 탭의 인덱스 역추적까지 필요해 QSS 한 줄보다 복잡
Rejected: 보조 글씨 색을 테마별 전역 변수 + `_apply_theme`에서 라벨 재도색 | 폴더 라벨은
  심볼 섹션 재구성마다 새로 만들어져 추적 목록이 필요 — 팔레트 역할은 자동 전파됨
Constraint: 팔레트 `PlaceholderText` 변경은 입력칸 placeholder 글씨에도 같이 적용된다
  (더 진해짐 — 같은 대비 원칙이라 의도된 부수효과)
Confidence: high
Not-tested: 탭 닫기 버튼 호버의 실제 마우스 체감(스크린샷은 평상시 상태만 확인)
