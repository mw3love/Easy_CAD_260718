## 3. 아키텍처 핵심 결정

**A. 좌표계 / 단위**
CAD 왕복과 A-size 인쇄를 위해 **mm 단위 월드좌표**를 채택(화면 픽셀과 분리). 무한 캔버스는 월드좌표 위에서 팬/줌. Y축 방향(CAD는 Y-up, 화면은 Y-down)은 DXF 입출력 시 변환.

**B. 문서 모델 (가장 중요한 리팩터 지점)**
pasteflow 편집기는 QGraphics 아이템을 사실상 모델로 쓰는 구조로 보임(`확인 필요` — grep만 했고 완독 안 함). Easy CAD는 결국 **모델↔뷰 분리**가 필요하다:
- 이유: DXF 매핑 · Undo/Redo · 저장/열기 · "객체 개별 인식" 전부 깨끗한 엔티티 모델을 전제로 함.
- 방침: v1은 속도를 위해 기존 아이템 구조를 최대한 재사용하되, **각 아이템이 직렬화 가능한 의미정보(타입·기하 파라미터)를 반드시 지니게** 설계한다. 정식 문서모델은 Phase 3(DXF 직전)에 도입 — 그때 리팩터 규모는 pasteflow 코어 완독 후 확정.

**C. Undo/Redo**
`QUndoStack` 기반 커맨드 패턴으로 Phase 1부터 도입(뒤에 붙이면 고통). 모든 편집을 커맨드로.

    **왜**: 세 창이 설명 칸·그림 첨부·모델·설정·진행 표시·넣기 버튼을 각자 한 벌씩 갖고 있고, 그림을 넣으면 Mermaid 창과
    사진→도면 창이 둘 다 도면을 만든다(차이는 "관계만 읽어 다시 배치" vs "모양 그대로"뿐). 이름도 기술 이름(Mermaid·SVG)이다.

    **확정 결정**
    - 자리: **오른쪽 기둥 패널**(켰을 때만 생기고, 속성·미니맵 카드는 그만큼 왼쪽으로). ⚠ 2026-07-29 "캔버스가 먼저"(칼럼
      예약 금지) 원칙의 **의도된 예외** — 시안에서 아래 가운데 막대·떠 있는 카드와 비교한 뒤 사용자가 골랐다.
    - 종류는 결과 이름으로 3개: **심볼 하나 · 흐름도 · 그대로 베끼기**(패널 맨 위 탭). 그림을 넣으면 흐름도(다시 배치)와
      베끼기(모양 그대로)를 둘 다 고를 수 있다.
    - 결과는 **캔버스에 임시로**(주황 점선) — 캔버스가 곧 미리보기. 놓는 곳은 만들기를 누른 순간의 화면 가운데, 우클릭
      「AI로 바꾸기」로 열었으면 그 도형 자리. 임시 결과가 남은 채 다른 작업·새 만들기·저장을 하면 **자동 채택**(Ctrl+Z로 지움).
      단 **심볼 후보 줄은 예외 — 하나도 안 고른 채 다른 작업을 하면 버림**(후보는 고를 거리, 기록에서 다시 만들기 쉬움).
    - 역할 나눔: **패널 = 입력 + 기록**(세 종류 같은 모양), **결과에 딸린 조절 = 결과 바로 위 막대**. 막대는 「채택 … 버리기」
      공통 + 가운데만 종류별(심볼: 모두 선택·이어 만들기·내 심볼에 저장 / 흐름도: 방향·이어 고치기 / 베끼기: 사진도 남기기·모서리
      초기화·다시 — 심볼·흐름도의 「다시」는 피드백 3·5차에서 뺌, 기록 칸을 누르면 다시 채워지므로).
    - 심볼 후보: 6개를 **캔버스에 줄지어** 놓고 클릭·칸 모서리 □로 고른 뒤 「채택」(피드백 1·3차 — 처음 안의 Ctrl+클릭은 이 캔버스에서
      선택을 바꿔 버려 폐기). SVG 창의 모델 B 칸은 뺀다(원래 기본 꺼짐).
    - 베끼기: 사진을 붙이는 순간 **캔버스에 흐리게 깔리고 모서리 점 4개도 캔버스 위에** — 결과가 사진 위에 겹쳐 나와 원본|결과
      나란히 보기가 필요 없다. 만드는 2~3분 동안 캔버스를 계속 쓸 수 있다.
    - 모델 고르기·코드 칸(Mermaid 코드·지시문 복사)은 **「고급」으로 접기**. 평소엔 종류별 추천 모델 자동. Mermaid 코드를
      직접 붙여 넣는 길(AI 없이)은 고급 안 「코드로 넣기」로 남긴다.
    - 기록: 앱이 켜져 있는 동안 모든 탭 공통, 끄면 사라짐. 이어 고치기는 처음엔 범위 밖이었으나 피드백 4차에서 심볼·흐름도에 넣음.
      바탕은 지우지 않는다(피드백 6차): 심볼은 후보 줄을 아래로 쌓고, 흐름도는 원본|새 결과를 나란히 놓아 다른 곳을 주황으로 표시,
      양쪽 막대가 같은 조절+「둘 다 넣기」, 비교에 안 끼는 쪽은 캔버스에 남김.
    - 메뉴·아이콘: 삽입 메뉴 세 항목과 상단바 아이콘 세 개를 「AI로 만들기」 하나(패널 켜기/끄기)로. 단축키 세 개
      (Ctrl+Shift+F·A·P)는 남겨 각각 그 종류로 패널을 연다.

    **끝 기준**: 실제 창에서 세 종류를 각각 만들어 채택·버리기·자동 채택·Ctrl+Z가 시안대로 되고, 옛 창 세 개(`_MermaidDialog`·
    `_SvgAssetDialog`·`_PhotoToDrawingDialog`)가 사라지고, 패널을 켜고 끌 때 다른 카드가 겹치지 않고, 전체 테스트 통과.
