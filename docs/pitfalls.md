# Easy CAD — 함정 모음

`CLAUDE.md`의 진행 기록(`docs/history/2026-07.md`·`2026-08.md`)에서 ⚠ 표시된 항목만 골라
"재발 방지"용으로 짧게 정리했다. 각 항목은 한 줄 교훈 + 상세가 있는 기록 파일 포인터.
새 버그를 만나면 여기부터 훑고, 자세한 진단 과정이 필요하면 포인터를 따라간다.

## Qt 시그널·이벤트 발화 조건
- `itemChange(ItemPositionChange)`는 `ItemSendsGeometryChanges` 플래그 없으면 아예 발화하지
  않는다 — `_ConnectorLabel` 자유이동 구현 중 발견. (`2026-07.md` FigJam 라벨 갭)
- `scene.changed`는 콘텐츠 변경에만 뜬다 — 휠줌·팬 같은 순수 뷰 트랜스폼은 안 탄다. 미니맵·
  화살표 reroute를 이 시그널에만 걸면 줌/팬 후 갱신이 안 됨. (`2026-07.md` 미니맵,
  `2026-08.md` boundingRect 최적화)
- 합성 `QMouseEvent`(press+move)는 이 앱 창에서 씬(`mouseGrabberItem`)에 델타로 반영되지
  않는다 — 오프스크린/자동화로 드래그를 재현할 수 없다는 뜻. 결과 상태가 필요하면 API 호출로
  대체(예: `setPos`/`apply_*` 직접 호출). pyautogui 같은 OS 레벨 자동화도 이 창에서는 클릭·선택
  자체가 안 먹힘(원인 미확정). (`2026-07.md` M4-4, `2026-08.md` 스마트 정렬 가이드)
- `QTabWidget`은 탭 전환과 무관하게 내부 `QStackedLayout.sizeHint()`가 **가장 큰 탭 크기로
  고정**된다 — 콘텐츠 크기로 패널이 줄어들게 하려면 탭 대신 `setVisible()` 토글. 숨김→재표시
  직후 `adjustSize()`는 레이아웃 무효화가 아직 반영 전이라 stale — `layout().activate()`를 먼저.
  (`2026-07.md` 캔버스-퍼스트 레이아웃)
- Qt 레이아웃은 부모 체인을 따라 **지연 전파**된다 — 자식 하나만 `activate()+adjustSize()` 해도
  조상(중첩 3단 이상)의 캐시된 sizeHint가 그 시그널 핸들러 안에서 즉시 안 바뀔 수 있다. 조상까지
  전부 activate 후 adjustSize. (`2026-08.md` 속성 dock 크기 버그 2건)
- `QMessageBox`(또는 임의 모달)를 모킹 없이 테스트에서 직접 호출하면 헤드리스 환경엔 누를
  사용자가 없어 `.exec()`가 영원히 블로킹 — 스위트 전체가 "멈춘 게 아니라 조용히 도는" 상태로
  보인다. 모든 모달 경로는 테스트에서 모킹 필수. (`2026-07.md` DXF/.ecad 통합)

## 좌표계·변환
- `drawForeground`의 painter는 Qt가 이미 **씬 좌표계**로 매핑해 넘긴다 — 여기에 다시
  `mapFromScene()`을 적용하면 이중 변환이 되어 원점 근처에서만 우연히 맞아 보인다. 미니맵
  인디케이터가 이 버그로 실사용에서만(데모 좌표는 우연히 통과) 어긋났다. 같은 증상이 재발하면
  트리거보다 **핵심 계산 자체**부터 재검증. (`2026-07.md` 미니맵)
- `fitInView(KeepAspectRatio)`는 뷰포트 종횡비가 극단(가로로 김)이면 레터박스가 커져 안의
  인디케이터가 실제보다 작아 보인다 — 미니맵류 패널은 좁고 세로로 긴 비율로 설계. 두 번
  반복된 함정(2026-07-28 dock, 2026-07-29 플로팅 패널). (`2026-07.md` 미니맵·캔버스-퍼스트 레이아웃)
- `_HandleResizeMixin.boundingRect()`가 회전 핸들(좌상단에만 존재)과 접속점을 union할 때, 한쪽만
  비대칭으로 튀어나오면 도형 중심이 실제 콘텐츠 중심에서 어긋난다 — 대칭 패딩으로 상쇄해야 함.
  (`2026-08.md` qc-dot/hover-port 통합)
- 아이템의 rect가 절대(씬) 좌표를 그대로 품고 `pos()`는 (0,0)에 남는 패턴(마우스로 그린 도형)이
  흔하다 — 정렬·스냅 기준점은 `pos()`나 로컬 원점이 아니라 `_content_rect()` 좌상단의
  `mapToScene()` 값을 써야 한다. (`2026-07.md` 그리드/스냅투그리드)
- `_scale_or_1`류 헬퍼가 아이템 자체 `.scale()`만 보고 뷰의 줌 배율을 무시하면, 확대할수록
  선택 테두리·핸들이 도형과 함께 커진다 — 뷰의 `isInteractive()`인 메인 캔버스 줌을 별도로 곱해야
  화면 픽셀 크기가 고정된다(Figma/AutoCAD 관례). (`2026-07.md` 실사용자 DXF 검증)

## 히트테스트·법선(포트/스냅)
- 도형 꼭짓점(마름모 E/W, 사각형 대각)은 두 변이 만나는 자리라 "최근접 변 하나"로 법선을 구하면
  변 선택이 임의가 되어 좌우 포트가 위아래로 드나든다 — 마름모는 의도된 축(N/S=수직·E/W=수평)
  강제, 사각형은 가까운 변 기준으로 강제. 보정은 **공유되는 저수준 함수**(`_nearest_border`)
  자체에 둬야 한다 — 상위 호출부 중 하나(포트 목록)에만 넣으면 다른 호출부(자동 라우팅)는
  여전히 옛 버그를 갖는다. (`2026-08.md` 8포트 확장)
- 재부착(끝점) 드래그 중 화살표가 **자기 자신의 다른 구간**에 스냅될 수 있다 — 스냅 함수에
  `exclude=self`를 반드시 넘겨야, 시각적으론 붙어 보여도 바인딩이 None으로 남는 사고를 막는다.
  (`2026-07.md` M4-4 최종 잔여)

## 라우팅(A*/직교 엘보)
- A* 격자(Hanan grid)에 화살표 자신의 좌표를 노드로 넣으면, 다른 화살표와의 교차점에 노드가
  얹혀 회피 벌점이 "눈멀게" 된다 — 회피 레인은 도형 팽창 모서리만으로 충분. (`2026-07.md`
  화살표-화살표 교차 회피)
- "부재"(증상: 안 나온다·안 걸린다)를 조사할 땐 **발생한 사례가 아니라 차단된 지점**을 찾아야
  한다. 게이트 플래그를 로그에 심어도, 발화한 줄만 grep하면 차단당해 안 찍힌 줄을 놓친다 —
  스턱루프 3라운드의 근본원인. (`2026-08.md` 스마트 정렬 가이드, 전역 규칙 11-b 「부재 확인」)
- 매 프레임(드래그 중) 국소 재정렬로 경로를 patch하는 접근은, 서로 다른 프레임의 판단이 서로의
  결과를 덮어쓰는 구조라 다중 프레임 드래그에서 표류한다 — "새로 그리기와 동일하게 전체
  재계산"으로 메커니즘 자체를 바꿔야 안정된다(3차 시도 끝에 확정). (`2026-08.md` 8포트 확장)
- 드래그 재설계로 점 개수가 매 프레임 바뀔 수 있게 되면, press 시점에 캡처한 "몇 번째 점"
  인덱스가 다음 프레임엔 범위 밖(IndexError)이 될 수 있다 — 인덱스는 매 프레임 유효 범위로
  재계산. (`2026-08.md` 8포트 확장, 끝점 드래그 크래시)
- "승자 하나 고르기" 안정화 규칙은, 두 후보의 거리가 **수학적으로 항상 일치**하는 경우(같은
  크기 도형의 좌/중심/우)엔 미세조정이 아니라 상시 발동하는 규칙이 되어 특정 정렬(변 정렬)이
  원리적으로 표시 불가능해진다 — 동률이면 하나만 고르지 말고 역할 전부를 동시 표시.
  (`2026-08.md` 스마트 정렬 가이드)
- 인접(마주보는 변) 후보에만 "교차축 범위가 겹쳐야 후보 인정" 게이트를 걸면, 두 도형이 정확히
  일치해도 게이트가 안 열려 후보에 못 오른다 — 같은 역할 매칭엔 이 게이트가 없는데 인접에만
  건 비대칭이 원인. 게이트 완화(+여유)가 아니라 **제거**가 정답이었다. (`2026-08.md` 스마트
  정렬 가이드)

## 검증 방법론
- 오프스크린(headless) 통과는 "해결"이 아니다 — 지속연결 초안이 offscreen은 통과했지만 실제
  GUI에서 버그가 났다(플로팅→고정 부착점으로 재설계). 전역 규칙 11-c "정직한 상태표기" 참조.
- 헤드리스는 한글 폰트가 없어 tofu(□)로 렌더된다 — 텍스트 정렬·크기 확인은 반드시 비-헤드리스
  `QGraphicsView.grab()` 또는 `python run.py` 실화면으로. (`2026-07.md` Mermaid import)
- `python run.py`를 사용자에게 대신 실행해 달라고 요청하기 전에, 이 환경은 Bash가 사용자와
  같은 대화형 데스크톱 세션이므로 `QT_QPA_PLATFORM=offscreen`만 빼고 직접 실행하면 실제 창·
  콘솔 로그를 스스로 확인할 수 있다(전역 규칙 11-d, 2026-07-31 확립). 정말 대리 불가능한 것
  (마우스 드래그 손맛·실기기)만 사용자에게 남긴다.
- 같은 증상이 두 번째로 재발하면(스턱루프 트립와이어) 트리거만 좁혀가지 말고 **핵심 계산 자체**
  부터 재검증한다 — 트리거를 의심하는 건 계산이 이미 맞다는 전제가 깔린 것인데, 그 전제가
  틀렸을 때는 헛수고다(미니맵 이중변환 사례).

## 하위호환·직렬화
- `.ecad`에 필드를 추가할 때는 항상 "키 없으면 안전한 기본값"으로 로드하게 만든다(예: 옛
  `routing:"ortho"`는 반경 0으로, `col_widths` 개수 불일치는 균등폭으로). 새 기본값이 옛 파일의
  시각 결과를 바꾸면 안 된다.
- 반환 계약이 이미 25곳 이상에서 소비되는 함수(`load_document`의 `int` 반환)는 타입을 바꾸지
  말고 별도 함수(`load_document_layers()`)로 분리 — 회귀 폭 최소화. (`2026-07.md` 레이어 패널)
