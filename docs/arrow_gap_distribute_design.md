# 연결된 화살표 간격 분배 — 설계 확정 (2026-08-23)

deep-interview로 확정한 설계. 07da027(정렬/분배 "첫 간격 기준 분배" 신설) 직후 사용자가
"사실상 화살표를 위한 기능인데 화살표는 안 된다"고 지적해 착수.

## 배경

`distribute_selection`/`distribute_selection_fixed_gap`(`host_context.py`)은 `_align_targets()`가
바인딩된(도형에 붙은) 화살표를 전부 제외한다 — "연결된 화살표는 reroute가 따라오므로 제외"라는
기존 주석대로다. 실측 확인(`host_canvas._on_scene_changed`): 바인딩된 화살표를 억지로
`moveBy()`해도, 다음 `scene.changed`에서 호스트 앵커 기준으로 즉시 재배선돼 원래 자리로
돌아간다(자석처럼 되돌아옴). 제외 규칙을 없애는 것만으론 해결 안 된다.

사용자 확인: 정리하려는 화살표는 **대부분 도형에 연결됨** + **서로 독립적인 연결(A→B, C→D)이
우연히 평행하게 지나가는 경우** + 배선 상태는 자동/수동(세그먼트 드래그로 이미 손댄 것) 둘 다
섞여 있음.

## 확정 결정

1. **화살표 전체를 옮기지 않는다.** 끝점은 서로 다른 도형에 박혀 있어 움직일 수 없다 —
   "평행하게 지나가는 구간(직교 세그먼트) 하나"만 옮기고 양 끝은 그대로 둔다.

2. **대상 세그먼트 선택 — 휴리스틱 없이 기계적으로.** 화살표마다 "가장 긴 매칭 방향
   세그먼트"를 고른다(세로 분배="세로 세그먼트" 중 최장, 가로 분배="가로 세그먼트" 중 최장).
   꺾이는 위치가 화살표마다 달라도 그 부분은 안 건드린다 — 사용자 제안("수평 영역만 서로
   인정해서 진행") 그대로. 매칭 세그먼트가 하나도 없으면(직선/곡선 라우팅 등) 그 화살표는
   대상에서 빠진다(안내 없이 조용히 skip — 기존 `distribute_selection`이 대상 부족 시
   no-op하는 것과 같은 관례).

3. **기존 계산식 재사용.** 세그먼트를 "분배축 방향 길이 0인 상자"로 취급해(가로 세그먼트는
   top==bottom, left/right=x 양끝) 기존 `_align_rect` 기반 정렬/분배 계산에 그대로 끼워
   넣는다. 새 수학 없음.

4. **적용은 기존 세그먼트 드래그 내부 함수 재사용.** `_PolyArrowItem._begin_segment_drag(seg_idx)`
   → `_drag_segment_to(scene_pt)` → `_end_segment_drag()`를 마우스 대신 계산된 좌표로 호출한다.
   이 함수들이 자동배선 해제(`_auto_route=False`)·양끝 스텁 보호·직교 유지·경유힌트 폐기를
   이미 다 처리한다 — 라우팅 탐색(A*) 코드는 전혀 안 건드림(이 프로젝트에서 가장 스턱루프가
   잦았던 민감 영역이라 리스크를 최소화하는 방향).

5. **undo — `push_undo_move`(도형)와 `push_undo_geom`(화살표, `capture_geom`/`apply_geom`
   기반)을 한 undo 엔트리로 묶는다.** `_push_entry(ops)`가 이미 서로 다른 sub("pos"/"geom")를
   섞은 리스트를 받는다 — 새 undo 메커니즘 불필요.

6. **적용 범위 — 분배(균등+첫간격기준) 2개만.** 정렬(6방향 맞춤)은 "여러 구간을 한 줄로
   포개는" 동작이라 화살표 간격정리 목적과 안 맞아 이번 스코프에서 제외(사용자 확인).

## 1차(v1) 구현 범위

**포함**:
- `_arrow_gap_targets(axis)` — 선택된 바인딩 화살표 중 `_is_ortho()`이고 매칭 세그먼트가
  있는 것만 골라 `(item, seg_idx, virtual_rect)` 리스트로 반환.
- `distribute_selection`/`distribute_selection_fixed_gap`이 기존 도형 대상(`_align_targets`)과
  위 화살표 대상을 합쳐 정렬·gap 계산 → 적용 단계에서 도형은 `moveBy`, 화살표는 세그먼트
  드래그 3종 함수 호출로 분기.
- 혼합 undo 엔트리(도형 pos + 화살표 geom, 한 번에 되돌아감).

**제외(후속 라운드)**:
- 정렬(6방향 맞춤)에 같은 방식 적용.
- 직선/곡선 라우팅 화살표 지원(대상에서 조용히 제외되는 현재 동작 유지).
