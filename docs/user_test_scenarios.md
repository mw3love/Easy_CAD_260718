# 실사용 검증 시나리오표

최종 검수 Phase 6(2026-08-26) 산출물. `Not-tested:` 백로그 353건 중 "손맛/환경 전용
— 자동화로 대리 불가" 버킷(약 260건)을 기능별 최소 경로로 압축했다. `python run.py`로
켜서 위에서부터 훑으면 된다 — 전부 한 번에 안 해도 되고, 새로 만지는 기능이 있을 때
그 절만 펼쳐서 써도 된다.

체크박스는 참고용(파일에 직접 체크해 git으로 진행상황을 남겨도 되고, 안 남겨도 됨).
버그를 발견하면 재현 절차와 함께 새 세션에서 보고 — 이 문서 자체는 안 고쳐도 된다.

## 1. 기본 캔버스 조작
- [ ] 도형 8종(사각형/원/삼각형/판단/시작끝/입출력/준비/저장소) 각각 생성 → 이동 → 리사이즈(모서리·변) → 회전 핸들로 자유회전
- [ ] 다중선택(러버밴드 window/crossing) → 그룹 변형(회전·균일/비균일 스케일) → stretch(걸친 정점만 이동)
- [ ] 화살표 3종(곡선/직선/직교) 그리기, 도형 테두리 스냅, 포트(N/E/S/W) 부착, 재부착(끝점 드래그)
- [ ] 화살표 라벨 다중 부착(빈 자리 더블클릭=새 라벨, 기존 라벨 더블클릭=재편집)
- [ ] 도형 중앙 라벨 편집(더블클릭), 텍스트 재편집 후 하이라이트 잔류 없는지
- [ ] Ctrl+Z/Ctrl+Shift+Z(undo/redo) — 이동·생성·삭제·스타일변경 각각 왕복
- [ ] Ctrl+D 복제, Ctrl+C/V 복사-붙여넣기, Alt+드래그 복제
- [ ] Shift+휠(선택 도형 두께/폰트크기 조절), 다중선택 시 일괄 적용
- [ ] 그리드/스냅투그리드(G키), 스마트 정렬 가이드선(이동 중 모서리·중심 정렬)

## 2. 다각형/펜 도구
- [ ] 다각형 도구(9번 단축키) — 클릭으로 정점 추가, 시작점 재클릭으로 닫기, 더블클릭/Enter로 열기
- [ ] 다각형 테두리 스냅(다른 도형에 붙이기), 닫기 예고 마커
- [ ] 펜 도구로 자유곡선 그리기, 양 끝 접속점 확인

## 3. TRIM/EXTEND
- [ ] TRIM 도구(T)로 교차 구간 클릭 1회 자르기, 드래그로 문지르기(Fence) 연쇄 자르기
- [ ] Shift+EXTEND로 열린 도형(선) 끝점 늘이기
- [ ] Shift+EXTEND로 닫힌 도형의 TRIM 자국 복구

## 4. 정렬/분배/그룹
- [ ] 정렬(좌/우/상/하/가운데) — **펜 두께가 서로 다른 도형 두 개**로 시도, 실제 테두리가 딱 맞는지 육안 확인(2026-08-26 회귀 수정분)
- [ ] 균등 분배(첫 간격 기준 포함), 연결된 화살표가 있는 배치에서도 동작하는지
- [ ] Ctrl+G 그룹/Ctrl+Shift+G 그룹해제, 그룹 자신의 큐닷으로 화살표 붙이기

## 5. 커스텀 심볼 팔레트("내 심볼")
- [ ] 선택 영역 우클릭 → 팔레트에 등록(폴더 지정 포함, "즐겨찾기로 등록"도)
- [ ] 폴더 생성/이름변경/삭제(삭제 시 소속 심볼도 함께 삭제 확인)
- [ ] 심볼 이름변경, 삭제, 즐겨찾기 토글(이중표시 확인)
- [ ] 심볼을 캔버스로 드래그해 배치(그룹으로 삽입되는지)
- [ ] 다중조각(SVG 등) 심볼 그룹에 화살표 붙이기(호버 예고점 뜨는지)
- [ ] **등록한 심볼의 팔레트 썸네일이 다크 테마에서 잘 보이는지** — 어두운 펜 색으로 그린 도형을 등록했을 때 특히 확인(§6-2 알려진 이슈, 원인은 규명됐으나 수정 보류 중)

## 6. 파일 저장/불러오기 (.ecad)
- [ ] 저장 → 앱 종료 → 재실행 → 열기 왕복(도형·화살표·라벨·레이어·그룹·잠금 전부 보존되는지)
- [ ] 옛 버전 `.ecad`(가능하면 몇 달 전 파일) 열기 — 하위호환 깨짐 없는지

## 7. DXF/DWG
- [ ] DXF 내보내기 → AutoCAD 등 외부 프로그램(있으면)으로 열어 육안 확인, 없으면 다시 가져오기로 왕복 확인
- [ ] **양방향 화살표(시작+끝 촉)를 DXF로 내보냈다 다시 가져와서 촉이 양쪽 다 보존되는지**(2026-08-26 수정분, 자동검증 완료 — 실제 파일 왕복으로 한 번 더 확인 권장)
- [ ] DWG로 저장 → 다시 DWG 열기(ODA File Converter 설치 필요)
- [ ] 외부(우리 앱이 안 만든) DXF 파일 가져오기 — 레이어색·INSERT/BLOCK·재스케일 확인

## 8. PDF/PNG/SVG 내보내기
- [ ] 표제란/용지틀이 있는 도면 → 내보내기 → 용지 크기·방향 콤보가 비활성화되고 "표제란 용지 설정을 따름" 안내가 뜨는지(§6-2, 의도된 동작 확인)
- [ ] 표제란 없는 도면 → 용지 크기·방향 직접 선택 → 실제 인쇄물 또는 PDF 뷰어에서 여백·비율 확인
- [ ] 선택 영역만 내보내기(비선택 도형이 함께 안 나오는지)
- [ ] 다중 페이지(용지틀 2개 이상) — 드롭다운으로 프레임 선택해 각각 내보내기
- [ ] PNG 투명배경, SVG 내보내기

## 9. Mermaid 가져오기
- [ ] 텍스트로 Mermaid 코드 직접 입력 → 가져오기
- [ ] AI로 설명→Mermaid 생성(게이트웨이 키 필요) → 실시간 미리보기 반영 확인
- [ ] 이미지 첨부→Mermaid 생성

## 10. AI SVG 에셋 생성
- [ ] 텍스트 설명으로 SVG 아이콘 생성(게이트웨이 키 필요), 후보 여러 개 동시 생성
- [ ] 이미지 첨부로 생성
- [ ] 생성 결과를 "내 심볼"로 저장, 캔버스에 삽입

## 11. 마인드맵(Tab/Enter)
- [ ] 도형 선택 후 Tab(자식 생성)·Enter(형제 생성) 연속 뻗기, 텍스트 바로 입력
- [ ] Alt+방향키로 특정 방향 생성
- [ ] **빈 노드에서 편집 취소(Esc 등)했을 때 화살표가 고아로 남는지**(§6-2, 알려진 미해결 — 재현되면 다음 세션에서 처리)

## 12. 단축키 설정
- [ ] 편집(&E) → 단축키 설정 창에서 임의 단축키 재할당, 실제로 그 키로 도구 전환되는지
- [ ] 중복 할당 시 경고 뜨는지

## 13. 성능(대형 도면)
- [ ] 도형 500~1000개 이상 문서에서 드래그·팬·줌 체감(끊김 없이 부드러운지)
- [ ] 화살표 많은 밀집 도면에서 도형 하나 이동 시 버벅임 없는지

## 14. 테마
- [ ] 다크↔라이트 전환, 아이콘·배경·기본 잉크색이 각각 적절히 바뀌는지
- [ ] 라이트 테마에서 선택 하이라이트·정렬 가이드선 대비 확인(§6-2 인접 항목, 실측 미완)
