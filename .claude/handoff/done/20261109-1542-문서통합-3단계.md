## 3단계에서 할 것(계획부터 — 승인 받고 진행)
1. **글자 손으로 고치기**: 큰 창(docview)에서 블록 글자를 직접 고침(contenteditable 등 — 지금 문서 틀은 스크립트 없는 `allow-same-origin`이라 앱이 바깥에서 다룰 수 있음). 표·그래프·그림은 AI로. 저장 = `setFields` html(Ctrl+Z).
2. **「이 블록 움직이게」**: 움직이는 카드(`live_card.py`·`livecard.js` — 스크립트 켠 sandbox+CSP)를 블록 단위로. 문서는 인쇄용 정지 문서라 인쇄·한글 파일에선 정지 모습으로 나와야 함 — 설계 필요(블록 자리에 「움직이는 칸」 표시 + 칠판/큰 창에서만 동작?). 대화창 「직접 움직여 볼 수 있게」(kind live) 길을 여기로 합칠지도.
3. **취재 한 판 정리**: 1단계에서 새로 만드는 입구가 없어짐(칩 「디자인」 뺌, 질문지 「한 판/여러 장」 전환은 11-08부터 켜는 곳 없음). 엔진(`deep_mode.py`·`deepboard.js`)·예전 지면 꼭지 다시 쓰기는 남아 있고 `web/e2e/flow33` 딥모드 시험은 `test.skip`. 지울지·문서 블록 기능에 흡수할지 사용자에게 묻기(찾아 보태기는 이미 `deep_mode.gather`를 문서가 씀).
