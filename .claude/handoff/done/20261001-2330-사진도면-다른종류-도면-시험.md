# 사진→도면 — 다른 종류 도면(건축·손그림 등)으로 범용 지시문 시험

생성: 2026-10-01 23:30

사진→도면(§8 항목28)은 앱에 들어갔고(삽입 메뉴 「사진→도면…」, `Ctrl+Shift+P`), 지시문도 범용으로 바꿨다
(`easycad/ai/photo_to_ops.py` `TASK` — 분야 문구 제거, 출력 형식·분야 무관 규칙만). 지금까지 시험한 사진은
전부 방송 송신소 계통도(1TV·DMB)뿐이라, 다른 종류 도면에서 어떻게 나오는지는 모른다. 경위:
`docs/history/2026-10.md` 맨 끝 "사진→도면 지시문 범용화".

할 일:
1. 사용자에게 다른 종류 도면 사진(건축 평면도·전기 단선도·손그림 순서도 등)을 받는다. 리포 `docs/reference/`의
   참고 이미지는 장비 랙 사진이라 맞지 않는다. 사진이 없으면 이 항목은 보류로 두고 끝.
2. `python tools/sketch_ops_probe.py <사진> --model gpt-6.1-sol --mode loop --rounds 2 --out-dir tools/_sketch_ops/<이름>`
   (PYTHONIOENCODING=utf-8, 1회 약 6분·~200 크레딧 추정). 앱과 같은 루프·렌더를 쓴다.
3. 원본과 `_r2.png`를 나란히 붙여 직접 보고 판단. 특히 건축이면: 문 여닫이 호(poly 근사가 되는지), 두꺼운 벽,
   빗금, 치수선 — ops 어휘에 arc·두께·해칭·치수가 없어서 부족할 수 있다. 부족하면 어휘 추가(예: `arc`)를
   계획으로 제안(코드 수정 전 승인).

판단 기준: 다른 종류 사진 1장 이상에서 "배치·선 대부분 맞음 / 어휘 부족으로 못 그리는 것 목록"이 정리되면 끝.
결과는 `docs/history/2026-10.md`(또는 그 달 파일) 끝에 기록.
