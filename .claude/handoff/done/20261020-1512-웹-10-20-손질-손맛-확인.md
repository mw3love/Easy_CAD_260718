# 웹 칠판 10-20 손질 손맛 확인 (다른 PC)

생성: 2026-10-20 15:12

10-20에 사용자 검토로 웹 칠판을 한꺼번에 손봤고 자동 시험(화면 42 · 데스크톱 233)은 통과했다. 남은 것은 **실제 크롬에서 손으로 써 보는 확인**뿐 — 사용자가 다른 PC에서 직접 써 보며 어색한 점을 말하면 그걸 고친다.
경위·결정 이유: `docs/history/2026-10.md` 끝 「2026-10-20 …」 세 항목. 커밋 `f035ba6`·`967a4f9`·`16df91e`.

시작: `git pull` → 서버 `python web/server.py --host 127.0.0.1` + `cd web && npm run dev` → `localhost:5190`.
⚠ 이 PC에서 KAIROS가 502였던 원인 = Vite 프록시가 `localhost`(Node 22 → IPv6 먼저)였음 → `vite.config.js`를 `127.0.0.1`로 고침. 다른 PC에서도 KAIROS 답·공유 버튼(서버 있을 때 진하게)이 보이는지 먼저 확인.

확인할 것(사용자에게 하나씩 써 보게 하고 반응을 받는다):
- 다각형: 첫 클릭부터 따라오는 선, 점 3개↑ 뒤 시작점 12px 안 = 붙고 파란 원, 누르면 닫힘
- 선: 클릭 두 번으로 긋기(드래그도 그대로)
- 빈 곳 두 번 누르기 = 글(안 쓰면 지워짐)
- 잠긴 도형 위 우클릭 「이 도형 잠금 해제」 / 「잠금 해제 (전체)」는 잠긴 레이어 것 안 건드림
- 위 막대 도구를 칠판으로 끌기: 선·화살표(120px)·다각형(첫 선분 + 이어 찍기)·펜·글자·번호·메모·표(마지막 행·열)·프레임·웹(주소 칸). 끌어 놓은 화살표는 도형에 저절로 안 붙음(안 만듦 — 원하면 다음 일)
- 메모·표·웹 버튼 = 가운데 먼저, 겹치면 가까운 빈자리
- 메모 = 만들면 고른 채(바로 끌기), **진짜 한글 IME로 바로 쳐서 첫 글자가 안 빠지는지**(자동 시험은 insertText 경로라 IME 조합은 미검증 — 가장 중요), 빈 메모 「치면 바로 써져요」
- `Z` 다 보기 · `Shift+Z` 고른 것만 · `D` 다크(안 골랐을 때) · 위 막대 「전체 화면」 · 데스크톱 `Z` 다 보기

판단 기준: 사용자가 어색하다고 한 것만 고친다. 같은 증상 두 번이면 규칙 11-b. 미뤄 둔 것(미니맵 그림 썸네일·미니맵 자리)은 UI/UX 디자인 라운드 몫 — 여기서 하지 않는다.
대기 중인 다른 인계 `20261019-2051-웹-실사용-후기-반영-데스크톱-4-3.md`가 더 오래됐으니 /handoff는 그걸 먼저 연다 — 사용자가 이 확인을 먼저 원하면 순서를 바꾼다.
