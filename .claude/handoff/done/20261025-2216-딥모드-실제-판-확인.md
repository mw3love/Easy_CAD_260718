## 할 일
1. 서버 파이썬이 바뀌었으니 5191 서버를 다시 켜고, `cd web && npm run build`(5191은 `web/dist` 사본).
2. 진짜 판 하나 만들기 — 주제 예: 「ATSC 3.0 송신 장비, 신입 교육용」(타임라인·숫자가 나올 만한 것). 확인:
   - 계획 카드에 「요약 그림 · AI 그림 · 판 내용으로」 꼭지가 주인공 뒤에 있고 예상 크레딧에 그림 몫이 들었나
   - 판에서 요약 그림이 겹침 없이 앉고, 그림 속 숫자가 판의 숫자와 같나(지어낸 숫자·문구 확인)
   - 속성 카드 「톤」 넷을 눌러 자리 그대로 색만 바뀌나
   - 꼭지 하나 고르고 「더 자세히」 → 대화창 「↺ 원래대로 보기」가 그 자리에서 번갈아 바뀌나, 요약 그림 꼭지를 골라 「숫자를 더 크게」 → 새 그림
3. 결과를 사용자에게 화면 캡처로 보여 주고 손맛(전후 버튼)을 물어본다.

## 판단 기준
겹침 0, 그림 속 숫자가 판과 같음(다르면 `summary_prompt` 지시 손질 — 함정 `docs/pitfalls.md` 끝 줄), 톤 바꿔도 자리 같음, 전후 버튼이 크레딧 없이 바뀜. 사용자 합격이 끝.
