# 베끼기 「부분 다시 베끼기」 설계·구현 (AI 패널 피드백 6번)

## 배경
2026-10-06 사용자 피드백 "베끼기도 심볼·흐름도처럼 이어 만들기(추가 AI 대화)를 하면 어떨까"에 대해,
전체 이어 만들기 대신 **부분 다시 베끼기**로 하기로 사용자와 합의했다(커밋 `1638d55`의 Rejected 트레일러 참고).
- 전체 다시 만들기를 버린 이유: 베끼기는 6구역을 동시에 생성해 한 번에 2~3분이 걸리고 비용도 그만큼 든다. 게다가 다른 곳이 새로 틀어질 수 있다.
- 같은 날 1~5번은 반영했다: 막대 「만들기」·「90° 돌리기」, 「취소」로 이름 변경, 코랄 안내글, 결과 사진은 「사진 보기」+진하기(도면엔 안 남음).
- 사용자가 1~5번을 직접 써 본 뒤 이 작업을 하는 게 순서다. 시작할 때 써 보니 어땠는지 먼저 물어본다(진하기 막대에 글씨가 필요한지도).

## 하려는 것(초안 — 설계는 사용자와 확정할 것)
- 베끼기 결과 막대(`host_aimake._on_trace_done`가 만드는 막대)에 「부분 다시」 버튼을 둔다.
- 누르면 사진 위에서 상자를 끌어 틀린 곳을 고르고, 한 줄 지시(예: "표 칸이 빠짐")를 받는다.
- 그 부분만 잘라 AI에 보내고, 상자 안의 기존 결과 도형을 새 결과로 바꿔 끼운다(되돌리기 한 칸).
