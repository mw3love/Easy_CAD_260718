# 예시 칠판 「▶ 차례로 보기」 단추 (새 기능 제안 2)

생성: 2026-11-03 09:18

## 무엇을
처음 온 사람(대회 심사위원)이 예시 칠판을 열면 지금은 전체 보기라 노트북(1366×768)에서 글씨가 안 읽힘(2026-11-02 실검증, Playwright 새 브라우저로 확인).
예시 칠판 위 띠(「예시 칠판 — 마음껏 만져 보세요 … ↺ 처음 모습으로」)에 「▶ 차례로 보기」 단추 하나 → 1번 프레임부터 발표처럼 넘겨 봄.

## 재료
- 예시 칠판 원본 `web/examples/intro/`(프레임 1~5 = 둘러보기 순서), 서버 POST `/api/example/<이름>`, 띠 = `main.jsx`(「↺ 처음 모습으로」 근처 — 규칙 ⑧ 예시 되돌리기는 따로 보이는 단추).
- 발표 = `Editor.startPresent(frameId)`·`present.jsx`(판서·레이저 막대 — 처음 온 사람에겐 막대가 복잡할 수 있음, 확인).
- 화면 규칙 `docs/web_ui_rules.md`(A1 코랄 채움은 판마다 하나 — 띠에 「↺ 처음 모습으로」가 이미 코랄이면 둘 중 무엇을 대표로 할지).

## 할 일
1. 작은 일이라 바로 만들어도 되지만, 띠 단추 모양·코랄 대표 하나 규칙은 P3(취향)일 수 있음 → 시안 하나 보여 주고 진행(design-bakeoff 0-b부터).
2. 화면 시험(`e2e/flow47` 예시 칠판 옆에) + 공개 칠판에서 새 브라우저(Playwright 새 컨텍스트)로 처음 방문 확인 — 노트북 크기·휴대폰 크기.
3. 휴대폰 최소판(`isPhone`)에서 띠·발표가 어떻게 보이는지도.
