# 다각형/폴리라인 도구 구현

생성: 2026-08-18 14:27

설계는 확정, 구현은 아직 착수 전. 전문은 `docs/polygon_tool_design.md`(설계 결정 전체)와
`docs/EasyCAD_계획.md` §8 항목21(포인터)을 먼저 읽을 것.

## 핵심 결정 요약(전문은 위 문서 참조)
- 별도 "다각형" 도구 신설(기존 드래그형 "선" 도구는 완전 무변경).
- 시작점 재클릭=닫아서 다각형 완성(새 닫힌 도형 클래스, 채움색·통짜 이동/리사이즈) /
  더블클릭·Enter=열린 폴리라인으로 종료 / Esc=취소.
- 데이터모델은 진짜 새 도형 클래스(`_LineItem` 체인 안은 기각). 닫힌/열린을 완전히 다른
  클래스 둘로 할지 `closed` 플래그 하나로 통합할지는 착수 시 `_PolyArrowItem`
  (`core_shapes.py:3760`)의 점 목록 구조 재사용 가능성부터 확인 후 판단.
- 1차(v1) 범위: 그리기+이동/리사이즈+undo+`.ecad` 저장/불러오기까지. DXF 내보내기·
  TRIM/EXTEND(§8 항목17과 동급) 연동은 후속 라운드로 제외.

## 시작할 때
1. `docs/polygon_tool_design.md` 전체를 먼저 읽는다.
2. 단축키 배정 확인(`core_view.py:83` 부근 `Qt.Key.Key_*` 매핑 — 1~9 중 비어있는 키 확인).
3. 신규 스모크 pytest 추가(`tests/` 관례 그대로), 실제 창(오프스크린 아님)에서 삼각형·
   오각형을 그려보고 저장→재로드 확인까지가 완료 기준.

## 참고 — 같은 세션에서 함께 처리한 별개 작업(이미 완료, 참고만)
Shift+휠 다중선택 일괄 두께조절 + 텍스트/라벨 폰트크기 확장, 속성패널 다중선택 개수
표시는 이 세션에서 이미 구현·검증·커밋·push까지 끝났다(`core_view.py`/`host_canvas.py`/
`host_style.py`). 다각형 도구와는 무관.
