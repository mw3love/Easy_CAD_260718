# 스냅·격자 토글 "텍스트+체크마크" 베이크오프

생성: 2026-09-25 17:25

`/design-bakeoff`로 상단 툴바의 스냅·격자 토글 모양을 정해 줘. 2026-08-02 1라운드에서
"토글은 **텍스트 라벨 + 체크마크**(점만 있는 슬라이더 금지)"로 확정됐는데, 지금도 아이콘만
있는 `QToolButton`이라 아직 반영되지 않았다(`~/.claude/design-system/projects/easy-cad.md`
"다음 단계" 절).

배경:
- 2026-09-25 UI 원칙 점검(0-b)에서 객관적 문제 5건은 고쳐서 커밋했다(`6eab2f0`, 경위는
  `docs/history/2026-09.md`). 이 토글이 남은 주관적 후보 중 첫 번째다.
- 확정 취향 중 이번 판단에 걸리는 것:
  - 스냅·격자는 **평소 계속 켜져 있을 수 있는 토글**이라 checked를 옅은 코랄 틴트
    (`rgba(218,119,86,35)`)로 둔다. 그리기 도구처럼 잠깐 켜지는 버튼(`#toolStrongCheck`,
    alpha 150+테두리)과 강도를 섞지 말 것.
  - 아이콘 색은 중립색(다크 `#ffffff` / 라이트 `#000000`)이고, 코랄은 버튼 배경 상태에만 쓴다.
  - 버튼에 글씨를 붙일지는 항목 밀도에 따라 갈렸다(`preferences.md`). 툴바가 빽빽하니
    글씨를 넣으면 폭이 얼마나 늘어나는지 실제 툴바 폭에서 확인할 것.
- 전달 경로는 **라이브 하네스**(실행 중인 앱의 툴바라 실제 폭이 판정의 전부다).
  후보는 스타일시트나 위젯 교체로 만들고, 원본은 채택된 뒤에 고친다.
- 관련 코드: `easycad/canvas/host_ui.py`의 `_build_toolbar`, `_apply_theme`(`btn_qss`,
  `_palette_accent_qss`). 스타일시트를 스핀박스와 형제인 위젯의 상위에 걸면 스핀박스 크기가
  줄어드는 함정이 있다(`docs/pitfalls.md`).

끝 기준: 사용자가 후보 하나를 지목해 확정한다. 코드 반영은 확정 뒤 별도 단계에서 하고,
그때 `python tests/test_easycad.py`가 전부 통과해야 한다.
