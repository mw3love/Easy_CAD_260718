# 웹 칠판 손맛 확인 나머지(웹 카드·코드 블록·범례/HTML·공동작업) → 2% 배율 문제 → 공동작업 2단계

## 할 일
1. **손맛 확인 2~5번을 사용자와 함께**(지난 세션에 드린 체크리스트):
   - 2 웹 카드: 주소 `Ctrl+V`, 들어가는 사이트는 두 번 눌러 조작, 막는 사이트(네이버·구글)는 그림 카드 + ↗ 새 탭.
   - 3 코드 블록: 코드가 든 KAIROS 답 → 고정폭·회색 바탕.
   - 4 범례(우클릭 「범례 만들기」·「다시 모으기」) / HTML 공유(인터넷 끊고 열기).
   - 5 공동작업: 비밀번호 서버를 따로 띄워 크롬 창 둘 — `python web/server.py --port 5192 --password test1234 --data <임시 폴더>` + `npm run build`. 서로 다른 도형 동시 수정·게시 링크(`/?view=`) 보기 전용.
   지적이 나오면 그것부터(원칙 「고치는 모습 = 결과」).
2. **저장된 시점 없는 칠판이 배율 2%로 열림**(원래 코드에서도 같음 — 확인함): 처음 열 때 화면 크기를 재기 전(`size` 0)에 전체 맞추기가 도는 것으로 추정(`web/src/next/main.jsx` `fit`·`open`). Playwright 창에서 확인, 사용자 크롬에선 확인 필요.
   `docs/pitfalls.md` 끝 「앞 화면을 일찍 return하면 ResizeObserver가 멈춤」과 관련 있을 수 있음.
3. **공동작업 2단계 — 계획부터**(큰 공사, 사용자 승인 뒤 실행): 같은 도형 동시 편집(글자 단위)·실시간 커서. 후보 Yjs. 1단계 구조는 `web/collab.py`·`web/src/next/sync.js`(도형 단위 합치기).
4. 그 뒤: 범용 웹 클리퍼(고른 글 → 메모, 지금 페이지 → 웹 카드, 그림 → 그림 카드, 처음엔 칠판 가장자리에 쌓기). 서버는 공동작업 열쇠·`/api/patch`로.

## 알아둘 것
- 개발 화면 `cd web && npm run dev` → `http://localhost:5190/?board=main`(사용자 칠판 — 시험은 `?board=claude_...` 따로). 저장 서버 `python web/server.py --host 127.0.0.1`(5191).
  시험 칠판 `claude_memo_test`·`claude_memo_test2`가 서버 데이터에 남아 있음(지워도 됨).
- 확인 기준: 웹 `npm test` 85, 데스크톱 `python -m pytest tests -q` 1429(이번 세션은 웹만 고쳐 안 돌림).
- 크롬 확장 도구(claude-in-chrome)는 브라우저가 둘 연결돼 있어 고르기 질문이 뜸 → 이번엔 Playwright로 확인함. Playwright 창이 가려지면 requestAnimationFrame이 안 옴(`docs/pitfalls.md`).
- 남은 사소한 것: 긴 주소 줄의 꺾이는 자리가 칠판(글자 단위)과 고치기 칸(CSS keep-all)에서 다름. 「고치는 중 주소 글자 일부가 안 보임」은 재현 못 함 — 다시 나오면 스크린샷 부탁.
