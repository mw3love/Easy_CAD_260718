1. 이 PC에서 서버 켜기: `python web/server.py --host 127.0.0.1`(5191) + `cd web && npm run dev`(5190) — `npm install` 필요할 수 있음. KAIROS 키는 `~/.claude/.secrets/easycad-gateway.key`(이 PC에 있는지 먼저 확인 — 없으면 대화·정리 기능 503).
2. 사용자에게 실사용 후기를 받고(있으면) 그 순서대로 고침. 후기가 없으면 Claude가 직접 화면을 찍어 보며 UI/UX 점검 라운드를 제안(디자인 베이크오프 스킬로 시안 비교 가능).

4. 맨 마지막: 데스크톱 ④-3 — 계획서 `docs/EasyCAD_계획.md` §8 항목61 ④(프레임 → 메모 보기 → 메모 고치기 → 웹 카드 → 범례, 두 앱 화면 나란히 대조, 웹 디자인이 굳은 뒤).
