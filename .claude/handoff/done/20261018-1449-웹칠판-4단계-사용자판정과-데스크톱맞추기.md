- 정해진 칠판 규칙(사용자와 합의):
  - 내보내기 = 「전체 / 고른 것」 둘만. 고른 것에 **종이틀**이 있으면 틀마다 한 쪽(틀 안은 고르지 않아도 전부), 틀 밖 고른 것은 마지막 쪽. 순서 줄 우선(지그재그)/칸 우선. 우클릭 「종이틀 모두 고르기」.
  - 종이틀 = 데스크톱 「빈 용지틀」(.ecad `titleblock` + `plain`) + 배율(scale). 틀 = 비율 고정 출력 영역, 꼭짓점으로 크기, 쪽 이름에 축척(「1:2.9」).
  - 표 글자: 자동 = 칸에 맞춰 줄임, 직접 = 그대로 + 칸이 늘어남(줄이지는 않음).
  - AI 카드 = 채운 네모(둥근 모서리 12) + 왼쪽 위 라벨(.ecad `label.align="left"`, 상자 `fit_text`) — 고치는 동안 상자도 같이 늘어남.
  - 번호 도구는 Esc·우클릭까지 계속, 그리는 도구 중 제자리 우클릭 = 도구 끝, `Ctrl+D` = 옆으로 20 + 되풀이.
- 웹이 .ecad에 새로 쓰는 칸: rect `radius`(데스크톱도 그림·저장), `fit_text`·`chat_at`·`label.align`, 표 `font`·`color`·`pen`·`cell_styles`·`cell_runs` — 데스크톱은 `document._WEB_ONLY_KEYS`로 **보존만**(그리지는 않음). 새 웹 전용 칸을 만들면 여기 같이 넣을 것(`tests/test_part52_web_extra.py`).

## 할 일(차례대로)
1. **사용자 판정 받기** — 마지막 턴에 확인 목록을 드렸고 답을 아직 못 받음. 새 세션 첫마디로 "판정 결과 알려 달라"고 하고, 지적이 오면 고친다. 확인 목록:
   - 내보내기: 종이틀 하나 + 틀 밖 도형 → 2쪽, 「종이틀 모두 고르기」 → 쪽마다·순서.
   - 종이틀 꼭짓점 크기·축척·「1:1로」, 여러 개 고른 바깥 상자 꼭짓점 크기 조절(**글자·선 굵기도 같이 커지는 게 괜찮은지** — 판단 받을 것).
   - 표 칸 직접 크기 → 표가 늘어남(**줄여도 표가 저절로 안 줄어드는 게 괜찮은지** — 판단 받을 것).
   - 고치는 중 「글자」 카드(굵게·색·형광펜 — 드래그한 부분), 표 칸 한글 빠른 입력 + Tab·Enter.
   - (판단 받을 것) 내보내기에서 CAD 도면틀(표제란 있는 용지틀)도 「쪽」으로 같이 나오는 게 괜찮은지.
2. **데스크톱 맞추기**(판정 뒤 모양 확정되면 한 번에): 종이틀 넣기·「종이틀로 감싸기」·쪽 순서 옵션(데스크톱 `pdf_export._reading_order`는 이미 줄 우선), 카드 왼쪽 위 라벨·자동 줄바꿈·`fit_text` 그리기, 표 `font/color/pen/cell_styles/cell_runs` 그리기, 둥근 모서리·표 속성 칸, 고치는 중 글자 카드, 복제 되풀이·번호 연속·우클릭 끝 등 「데스크톱에 옮길 후보」(계획서 §8 항목61 4) 블록).
3. **5단계 갈아타기**(계획서 §8 항목61 5)) — tldraw 빼기, 서버에 쌓인 tldraw 칠판을 .ecad로.

## 알아둘 것(함정)
- 개발 화면 `cd web && npm run dev` → `http://localhost:5190/next.html?board=claude_props`(시험용 — 사용자 칠판 `main`은 보기만). 저장 서버 `python web/server.py --host 127.0.0.1`(5191, `/api/symbols` 포함 — 코드 바꾸면 서버 다시 켜기).
- Playwright 시험: 같은 페이지에서 시험을 이어 돌리면 앞 편집 상태가 남아 엉뚱한 실패가 남 → 시험마다 `page.goto`로 새로. 손잡이가 오른쪽 대화창(360px) 밑에 가려지면 클릭이 안 감 → 화면을 옮긴 뒤 누르기. 인쇄 창은 띄우면 시험이 멈춤 → iframe `print`를 가로채 HTML을 `page.pdf`로.
- TipTap: `commands.focus()`는 다음 그리기 때 돌아 늦음 → `text.focusNow`(view.focus 바로). 편집기 안 단축키에서 상태를 바꾸면 다시 그리기 전에 다음 키가 옴 → `R.current`를 그 자리에서 갱신(`finishCell`).
- 긴 편집은 스크래치패드 .py 스크립트(`patch()` + assert)로 — heredoc은 따옴표·`\n` 문제, 바꿀 문자열 끝 줄바꿈 빠뜨리면 두 줄이 붙음(이번에 빌드 깨짐).
- 확인 기준: 웹 `npm test` 58, 데스크톱 `python -m pytest tests -q` 1417(5분 넘음 → 뒤에서 돌리기).
