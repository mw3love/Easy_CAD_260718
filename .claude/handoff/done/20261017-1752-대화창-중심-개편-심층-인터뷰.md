# 대화창 중심 개편 — 심층 인터뷰로 범위·순서 정하기

생성: 2026-10-17 17:52

`deep-interview` 스킬로 사용자와 인터뷰해, 아래 구상의 범위·순서·완료 기준을 정하고 계획서(`docs/EasyCAD_계획.md` §8)에 새 항목으로 올린다.
**코드는 고치지 않는다**(설계 결정 단계). 계획서 규칙상 "큰 설계 필요 — 시작 시 deep-interview 필수" 항목이다.

## 사용자 구상 (2026-10-17, 사용자 발화 요약)
- 정체성: 처음엔 CAD를 쉽게 그리려고 시작했지만, 이제는 **전자칠판 + 내 자료로 배우는 최고의 AI 선생님**. Claude 아티팩트와 NotebookLM의 장점을 취하고 싶다.
- NotebookLM = 3분할(왼쪽 소스 · 가운데 채팅 · 오른쪽 스튜디오 버튼). 웹 AI(GPT·Claude) = 왼쪽 채팅 + 오른쪽 뷰어(아티팩트). 우리 작업영역 = 그 뷰어.
- 공통점은 **계속 이어지는 AI 대화창** — 우리는 예전에 있었지만 지금은 없다. 조각마다 AI는 있지만 처음 AI 창에서 이어지는 연속성이 떨어진다.
- 대화 답(PDF 내용 설명 등)이 마음에 들면 **드래그해서 작업영역에 붙여** 화이트보드를 채워 간다.
- **한 장 = 인포그래픽, 여러 장 = PPT.** 보드에 못 넣은 여분 조각이 PPT 재료. 한 장 인포그래픽과 전체 PPT를 같이 보여 주는 것도 괜찮다.
- **이미지 생성(gpt-image)** 검토 — GPT 인포그래픽도 완성도가 높고 아티팩트로 못 하는 부분이 있다. 보드 안에 넣을지, 병렬로 나열할지.

## 이번 세션에서 낸 의견(인터뷰 출발점, 확정 아님)
- 대화창: 오른쪽 접었다 펴는 칸, 가운데 칸 「무엇을 그릴까요?」를 그 대화의 첫 입력으로 합치기.
- 3분할 그대로는 작업영역이 크게 줄어 10월 첫 화면 결정("작업영역 넓게")과 부딪힘 → 소스는 작은 카드(자료 A·B·C 체크), 스튜디오 버튼은 대화 칸 위 빠른 버튼.
- 답 끌어다 붙이기 → 조각이 되게(지금 조각 체계 — 끌어다 넣기·「보드로 정리」·「종이로」 — 에 올라탐).
- PPT: 「종이로」가 이미 16:9 쪽 나누기·PDF 여러 쪽을 함. 남은 것 = 보드 옆 쪽 줄(슬라이드 목록) + .pptx 내보내기(지금 코드에 pptx 라이브러리 없음 — 새 의존성).
- 이미지 생성: 앱 게이트웨이(`easycad/ai/gateway.py`)는 글 생성(그림 입력 포함)만 있고 이미지 생성 호출 없음(확인함). 추천 = "보드 안 그림 블록 하나"
  (비유·표지 그림만, 글 많은 내용은 X — 한글 오류·"끝까지 고칠 수 있다" 원칙·비용).

## 열린 질문(인터뷰 재료)
- 대화 기록을 .ecad에 저장할지(문서마다 대화가 따라다니나), 소스 목록도 파일에 묶을지.
- 경진대회 시연 흐름에서 대화창이 필수인지, 시연 전에 어디까지 되어야 하는지(마감일은 아직 미확인).
- 이미지 생성 비용·모델(gpt-image 등 게이트웨이 지원 여부 확인 필요), 회사 보안 정책.
