두 가지 원래 있던 테스트 환경 문제를 고친다. 둘 다 2026-10-11 피드백 작업(커밋 eb160e5·b3ce3f2·dd7b877) 중 발견했고, 그 변경과는 무관함을 확인했다.

**1. `python -m pytest tests` 한 번에 돌리면 앱이 출력 없이 꺼짐(exit 127)**
- 위치: `tests/test_part29_ai_panel.py` 근처(약 27~32% 지점). 꺼지는 테스트가 실행마다 다르다 — `test_wide_result_zooms_out_to_fit_between_side_cards`, `test_other_edit_auto_accepts`, `test_accept_keeps_items_and_clears_marker` 등.
- 변경 전 코드(git stash)에서도 똑같이 꺼짐을 확인. `tests/test_part2*.py`만 묶어 돌려도 재현됨. 파일 하나씩(`pytest tests/test_partNN_*.py`) 돌리면 30개 전부 통과.
- 추정: PyQt6 가상 함수·슬롯 안에서 처리 안 된 예외(→ exit 127, 출력 없음 — `docs/pitfalls.md` 2026-10-11 항목). 앞 테스트가 남긴 창·타이머·워커 스레드가 다음 테스트 중에 지워진 객체를 건드리는 순서 의존 문제일 가능성. 확인 필요.
- 시작점: `python -X faulthandler -m pytest -v -s -p no:cacheprovider tests/test_part2*.py`로 재현 → 범위를 이분해서 어느 앞 파일과 짝일 때 꺼지는지 좁히기. `sys.excepthook`을 테스트에서 출력하도록 걸면 예외 내용이 보일 수 있음.
- 끝 기준: `python -m pytest -q tests`가 끝까지 돌아 통과/실패 숫자를 내는 것(두 번 연속).

- `HKCU\Software\EasyCAD-pytest\EasyCAD`에 `dark=false`가 남아 "다크 기본" 테스트 2개가 실패했다(`test_part10_multi_doc.py::test_new_tab_inherits_current_theme_background`, `test_part1_ui_arrows.py::test_dark_mode_toggle`). 그 값만 지워서 임시로 해결함.
- 할 일: 어떤 테스트가 다크 모드를 끄고 원래대로 돌려놓지 않는지 찾아 정리(테스트 끝에 되돌리기 또는 conftest에서 매 테스트 전 설정 초기화). 확인: `reg query "HKCU\Software\EasyCAD-pytest\EasyCAD"`.
- 끝 기준: 전체 스위트를 돌린 뒤에도 `dark` 값이 남지 않거나, 남아도 다른 테스트가 영향을 받지 않음.
