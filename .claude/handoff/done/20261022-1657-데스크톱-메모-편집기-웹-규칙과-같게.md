# 데스크톱 메모 편집기를 웹 TipTap 규칙과 같게 + 손맛 묶음

생성: 2026-10-22 16:57

## 배경(사용자 방향, 2026-10-22)
「데스크톱 = 웹 + 추가 기능 — 웹의 사용 경험이 데스크톱으로 그대로 이어지는 게 목표」. 웹에 있는 동작은 데스크톱도 **같은 글쇠·같은 규칙**,
다르게 할 땐 이유를 기록(`CLAUDE.md` 목표 「데스크톱 방향」). 사용자는 버그·UX 판단을 Claude에게 맡김 — 「검토하고 의견줘」면 고치지 말고 의견 + 선택창(규칙 12).

## 지금 상태
- 데스크톱 메모 제자리 편집기 = `easycad/canvas/core_memo_edit.py`(`_MemoTextEdit` — 메모 자식 `QGraphicsTextItem`, 줄 ↔ 문서 `lines_to_doc`·`doc_to_lines`).
  메모 그리기 `core_memo.py`, 웹 종류 그림 `core_web.py`, 시험 `tests/test_part66_desktop_web_kinds.py`(15).
- 사용자 지적(그대로 남음): `---`가 Enter를 기다림, `` `코드` ``가 안 됨, Ctrl+Enter가 웹과 다름. Claude 확인 결과 다르게 할 이유 없음 — 웹 규칙을 다 안 옮긴 실수.

## 이어서 할 일 — 1차(작음~중간)
**먼저 웹 기준 규칙을 목록으로 뽑는다**(기억으로 재구성 금지 — 이번 실수의 원인): `web/src/next/memoedit.jsx` 확장 목록(97~99줄)·`Finish` 글쇠(39~41줄)·`marks.js`,
`web/node_modules/@tiptap/extension-*/dist/index.js`의 `InputRegex`·`Mod-` 글쇠. 확인해 둔 것:
- 입력 규칙: 구분선 `/^(?:---|—-|___\s|\*\*\*\s)$/`(세 번째 `-` 치는 순간), 코드 블록 `/^```([a-z]+)?[\s\n]$/`(띄어쓰기·Enter), 글 속 코드 `` /(^|[^`])`([^`]+)`(?!`)$/ ``,
  굵게 `**x**`·`__x__`, 목록 `/^\s*([-+*])\s$/`, 번호 `/^(\d+)\.\s$/`, 제목 `#{1,3} `, 인용 `> `, 할 일 `[ ]`·`[x]` + 띄어쓰기. (기울임·밑줄·취소선은 웹도 입력 규칙 없음 — 글쇠만)
- 글쇠: Ctrl+Enter = 할 일 줄이면 체크·해제, 아니면 마침(10-18 사용자 선택) · Esc = 마침(웹은 + 그 줄 고르기) · Ctrl+B/I/U · Ctrl+E 코드 · Ctrl+Shift+X 취소선 ·
  Ctrl+Shift+7/8/9 번호·목록·할 일 · Ctrl+Alt+1~3 제목 · Ctrl+Shift+B 인용 · Ctrl+Alt+C 코드 블록 · Ctrl+/ 전환 메뉴(2차).
- 코드 블록 나가기: 웹 = 빈 줄 두 번(Enter 세 번), 데스크톱 지금 = 빈 줄 한 번. 붙여넣기: 웹은 마크다운·웹 글 → 메모 줄 — 데스크톱 편집기 붙여넣기가 서식째 들어오는지 **확인 필요**.
**만드는 법**: 위 규칙을 `core_memo_edit.py`에 표 하나(정규식·글쇠 → 동작)로 두고, 시험이 그 표의 줄마다 데스크톱에서 실제로 쳐 봄(웹 `e2e/flow9-keys`가 `keys.js` 표를 줄마다 확인하는 방식).
한글 IME 조합 중엔 규칙이 끼어들지 않게(지금은 띄어쓰기 순간에만 확인 — 글자 단위 규칙(`---`·백틱·`**`)을 넣을 때 조합 중 글자 확인).
끝의 기준: 표의 모든 줄이 데스크톱에서 웹과 같은 결과(시험), 데스크톱 전체 시험 통과, 실제 앱 화면으로 한 번 확인.

## 2차 묶음(그다음 — 크기 중간~큼)
- 메모: 글 고르면 꾸미기 막대(웹 `formatbar.jsx` — 색·형광펜·굵게 등), Ctrl+/ 전환 메뉴, Esc 뒤 줄 고르기·줄 손잡이 ⠿(웹 줄 고르기와 한 묶음).
- 손맛(10-22 웹 `keys.js` 기준 점검 — `docs/history/2026-10.md` 끝): 도형 고르고 바로 치면 글 · 위 막대 버튼 칠판으로 끌어 넣기 · 빈 곳 두 번 누르기 = 글 · Ctrl+X ·
  Alt+Z(고른 것만)·Z 한 번 더(보던 자리로) · Ctrl+F 찾기 · 표 칸 고르고 바로 쓰기·방향키. 낮음: D 다크(데스크톱 Ctrl+Shift+L), 휠 클릭(데스크톱 = 창 이동 — 바꿀지 사용자 결정).
- 작업실 때: 프레임 동작·발표·PDF 넘겨 보기·범례 자동·주소 → 웹 카드.
