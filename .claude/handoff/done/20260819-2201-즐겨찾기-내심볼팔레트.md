# '내 심볼' 즐겨찾기 기능 — deep-interview로 스코프 정리 후 구현

완료: 2026-08-20 (같은 세션에서 deep-interview → 구현 → 실제 창 검증까지 완료)

생성: 2026-08-19 22:01

## 배경

같은 날(2026-08-19) 좌측 "도형" 패널의 "내 심볼" 섹션을 재개편(최상단 접기 제거, 폴더별
개별 접기, 이름변경·삭제 우클릭 메뉴 통합)하고 실사용 피드백 4건(코랄 버튼 색·폭 흔들림
버그·폴더 삭제 정책 전환)을 반영해 커밋까지 끝났다(`fix(symbol-palette): 좌측 패널 접기
재개편 + 실사용 피드백 4건 반영`). 그 과정에서 사용자가 이런 의견을 냈다:

> "지금 미분류가 딱히 애매해진듯. 그래서 그걸 즐겨찾기로 하는건 어떤지? 에셋 우클릭 해서
> 즐겨찾기 추가하는것도 좋을듯하고."

## 지난 세션에서 정리한 것 (검토만, 코드 변경 없음)

"미분류"를 "즐겨찾기"로 **완전히 대체**하면 데이터 모델이 깨진다는 걸 지적했다 — 폴더가
지정 안 된 심볼은 항상 어딘가에 있어야 하는데, 즐겨찾기는 본질적으로 "즐겨찾기 안 함"인
심볼도 존재할 수 있는 개념이라 서로 안 맞는다(모든 심볼이 강제로 "즐겨찾기됨" 취급되는
꼴이 되어 즐겨찾기라는 이름 자체가 무의미해짐).

**제안한 대안(추천): 대체가 아니라 추가.**
- 미분류는 지금처럼 "폴더 미지정 심볼의 기본 보관함"으로 그대로 둔다.
- "즐겨찾기"를 완전히 별도의 새 섹션으로 신설 — 아무 폴더에 속한 심볼이든 우클릭 →
  "즐겨찾기 추가"로 그 섹션에 핀 고정(원본은 원래 폴더에 그대로 남고, 즐겨찾기는 참조/링크
  개념).
- 원본 심볼을 삭제하면 즐겨찾기에서도 당연히 사라져야 함(동기화 필요).
- 폴더 자체를 삭제하면(2026-08-19부터 폴더 삭제는 **완전 삭제** 정책으로 바뀜, 안의 심볼도
  함께 사라짐) 그 폴더 안에 즐겨찾기된 심볼이 있었다면 즐겨찾기 목록에서도 자동으로
  빠져야 함.

## 다음 세션에서 할 것

이건 새 기능이라 **`deep-interview` 스킬로 스코프를 먼저 정리**한 뒤 구현한다(전역
CLAUDE.md 규칙 6 — 이 정도 규모는 코드 작성 전 모호하면 멈추고 물어야 함). 열린 질문들:

1. **저장 방식** — `symbol_library.json`에 심볼 항목마다 `"favorite": true/false` 필드를
   추가하는 게 가장 단순해 보임(폴더 필드 `"folder"`와 같은 패턴). 아니면 별도 즐겨찾기
   id 목록을 따로 관리? (전자를 추천 — 폴더와 대칭적이라 기존 코드 패턴 재사용 쉬움,
   원본 삭제 시 자동 동기화도 공짜로 됨.)
2. **UI 위치** — "즐겨찾기"를 "내 심볼" 안 최상단(미분류보다 위)에 넣을지, 완전히 독립된
   새 아코디언 섹션(기본도형·내 심볼과 나란히)으로 뺄지.
3. **표시 방식** — 즐겨찾기된 심볼은 원래 폴더에서도 여전히 보이는 "이중 표시"(구글
   드라이브 방식)로 할지, 즐겨찾기 섹션에만 보이고 원래 폴더에서는 숨길지(단일 표시).
   이중 표시가 일반적인 UX 관례이자 구현도 더 단순함(추천).
4. **폴더 완전삭제와의 상호작용** — 위에서 언급한 자동 정리 필요(3.의 답에 따라 구현
   위치가 달라짐 — 이중 표시면 `favorite` 필드가 그 심볼과 함께 삭제되면 끝, 별도 id
   목록 방식이면 목록에서도 명시적으로 제거하는 코드가 필요).
5. **우클릭 메뉴 라벨** — "즐겨찾기 추가" / 이미 즐겨찾기된 경우 "즐겨찾기 해제"로 토글
   표시할지, 별도 액션 2개로 나눌지.

## 참고 코드 위치

- `easycad/fileio/symbol_library.py` — `folder` 필드 패턴이 참고 모델(`add_symbol`/
  `move_symbol`/`delete_folder` 등). 즐겨찾기 관련 함수(`toggle_favorite` 같은)도 이
  파일에 같은 스타일로 추가하면 됨.
- `easycad/canvas/host_ui.py` — `_refresh_custom_symbol_section`/`add_group`(폴더 그룹
  렌더링 로직, 즐겨찾기 섹션도 비슷한 패턴), `_show_custom_symbol_context_menu`(심볼
  우클릭 메뉴 — 여기에 "즐겨찾기 추가/해제" 액션 추가).
- 테스트는 `tests/test_part7_symbol_library.py`(심볼 라이브러리 전담 파일)에 이어서 작성.
