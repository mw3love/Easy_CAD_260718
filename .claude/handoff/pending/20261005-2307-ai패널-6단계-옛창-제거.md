# AI 만들기 패널 6단계 — 옛 창 세 개 제거·단축키를 패널 종류 열기로

생성: 2026-10-05 23:07

§8 항목36(「AI로 만들기」 오른쪽 기둥 패널) 1~5단계와 사용자 피드백 1~6차가 끝났다(최종 커밋 `453ed99`, 전체 1282 통과, push됨 — 2026-10-06 갱신).
6차에서 `host_fileio._build_mermaid_items`가 상자 크기를 글에 맞추게 됐다(`_mermaid_node_size`) — 옛 Mermaid 창 미리보기(`host_dialogs` 약 947줄, 120×56 고정)는 창과 함께 사라지니 맞출 필요 없음.
설계·결정 전부: `docs/EasyCAD_계획.md` §8 항목36, 경위: `docs/history/2026-10.md` "AI 만들기 패널" 항목들(설계 → 1~5단계 → 피드백 1~6차).

남은 6단계:
1. 옛 창 제거 — `host_dialogs._MermaidDialog`·`_SvgAssetDialog`, `photo_dialog._PhotoToDrawingDialog`(창 클래스만; `_PhotoOpsWorker`·
   `_pil_to_pixmap`·`PHOTO_MODELS`·`_MermaidGenWorker`·`_SvgGenWorker`·`_ModelListWorker`·`_SaveToSymbolsFolderDialog`·
   `_ImageAttachMixin`·`_AIGatewaySettingsDialog`는 패널이 쓰므로 남김). 호출부: `host_fileio._insert_mermaid`·`_insert_ai_svg_asset`·
   `_insert_photo_drawing`·`_get_*_dialog`, `host_context._generate_svg_replace`(우클릭은 이미 「AI로 바꾸기」→패널), 삽입 메뉴의 옛 세 항목
   (`host_ui` `_act_mmd`·`_act_ai_svg`·`_act_photo`). 옛 창 전용 테스트(`tests/test_part9_ai_mermaid.py`·`test_part9_ai_svg_asset.py`의 다이얼로그
   테스트)는 지우되, 생성 함수·파서·배치 테스트는 남긴다. `_build_mermaid`·`_build_mermaid_items`·`_build_photo_drawing`·
   `_save_svg_candidates_to_symbols`·`_svg_text_to_items`는 패널이 쓴다.
2. 단축키 — `shortcuts.py`의 `insert_mermaid`·`insert_ai_svg`·`insert_photo` id는 재사용 금지 규칙이 있으니 id는 그대로 두고 라벨만
   "AI 패널: 흐름도/심볼/베끼기 열기"로, 동작은 `_set_ai_panel_visible(True, kind=...)`. 기본값 F·A·P 유지.
3. `CLAUDE.md` "UI 원칙 — AI 보조 생성 UI"를 패널 방식으로 갱신(모델·코드는 고급, 결과는 캔버스 임시 결과, 이어 만들기), 구조 표에서 옛 창 언급 정리,
   계획서 항목36을 완료로.
4. 끝 기준: 메뉴·상단바·단축키로 세 종류가 다 패널에서 열리고, 옛 창 코드가 사라지고, 전체 테스트 통과, 실제 창 확인.

주의: `symbol_library/symbol_library.json`에 사용자가 써 보며 만든 `test11`·`ㄷ34` 폴더가 미커밋으로 남아 있다 — 사용자 결정으로 건드리지 않음.
패치는 셸 heredoc 대신 Write로 파일을 만들어 실행할 것(이번 세션에서 `\n`이 진짜 줄바꿈으로 깨진 일 2번).
