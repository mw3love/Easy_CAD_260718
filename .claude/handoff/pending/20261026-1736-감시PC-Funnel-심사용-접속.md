# 감시 PC에서 웹 칠판 서버 + Tailscale Funnel 8443 열기 (대회 10월분 심사용 접속)

생성: 2026-10-26 17:36

이 세션은 **전주총국 감시 PC**에서 연다(사용자 계획 — 그 PC에서 git pull 후 Claude Code). 그 PC엔 cimon reverse 프로젝트가 이미 Tailscale Funnel을 쓰고 있다.

배경: 2026-10-26 중간점검으로 「대회가 먼저」(CLAUDE.md `## 목표` 「지금 단계」). 10월분 마감 **2026-10-28 18시**. 기획서(`대회/KAIROS_제안서_MagicBoard_10월.hwp`) 비고에
「접속 주소(심사용 비밀번호 별도 안내)」라고 적었으니 이 주소가 있어야 사실이 된다. `대회/` 폴더는 git 밖이라 이 PC엔 없다(기획서·캡처 PDF는 회사 PC에 있음).
왜 Funnel인가: http로 IP 접속하면 브라우저가 마이크·클립보드를 끔(10-26 실측 `isSecureContext` false) → 🎙 회의·🎤가 안 됨. Funnel = 정식 https.

할 일(끝의 기준 = 다른 PC·휴대폰 브라우저에서 https 주소로 들어가 비밀번호 로그인 → KAIROS 대화 답이 오고 🎙 회의 버튼이 마이크를 묻는다):
1. 준비: `git pull` → `pip install -r requirements.txt` → `cd web && npm install && npm run build`(Node 24·Python 3). 빌드 안 하면 옛 화면.
2. 키 파일 `~/.claude/.secrets/easycad-gateway.key`(첫 줄 = KAIROS 키). ⚠ 키는 사용자가 메모장으로 직접 — 대화·`!` 명령에 치게 하지 말 것(8월 노출 사고). 이미 있으면 그대로.
3. 서버: `python web/server.py --host 127.0.0.1 --password <심사용 비밀번호>` (백그라운드). 127.0.0.1 = 바깥은 Funnel로만. 비밀번호 없으면 인터넷 누구나 칠판·크레딧을 씀 — 필수.
4. Funnel: `tailscale funnel status`로 cimon 포트 먼저 보고 → `tailscale funnel --bg --https=8443 5191` → status에 `https://<이름>.<tailnet>.ts.net:8443`, cimon 줄 그대로인지.
   8443이 차 있으면 10000(Funnel은 443·8443·10000만 — 공식 문서). 경로 나누기(`/board`)는 안 됨(칠판이 `/api`·`/assets`를 맨 앞부터 적음).
5. 확인: 그 주소를 브라우저로 — 로그인 창, `window.isSecureContext === true`, 대화 한 번(검색 5크레딧쯤), 🎙 회의 = 마이크 권한 창. 휴대폰(LTE)으로도 한 번(사용자).
6. 공유 장면 다시 찍기: 그 칠판에서 「공유」 창 캡처(비밀번호가 있으니 「비밀번호가 없어요」 경고가 없어야 함) → 사용자에게 회사 PC로 보내 PDF 7쪽(`07_공유.png`)을 바꾸게. PDF는 회사 PC `대회/capture/` 그림 + 맑은 고딕으로 만들었음.
7. (선택) 시연 칠판 옮기기: 회사 PC `%APPDATA%\EasyCAD\web_boards\demo_1026.*`(.ecad·.chat.json·.img 폴더)를 그대로 감시 PC 같은 폴더로 복사하면 심사위원이 완성된 예시 칠판(`?board=demo_1026`)을 봄. 복사는 사용자 손.

주의: 서버 창을 닫으면 칠판도 꺼짐(대회 기간 켜 둠). 서버 Python을 고치면 서버를 다시 켜야 반영. 심사위원 크레딧 = 서버 키(남은 약 13,400/월) 또는 「내 키」 — 어느 쪽으로 할지, 비밀번호 전하는 법은 열린 질문(사용자).
끝나면 `docs/history/2026-10.md`에 주소 모양(실제 tailnet 이름은 적지 말지 사용자에게 물을 것)·확인 결과를 적는다.
