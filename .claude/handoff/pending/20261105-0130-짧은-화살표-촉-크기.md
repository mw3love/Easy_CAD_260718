## 끝 기준

- 선 길이가 촉보다 짧은 화살표는 촉을 선 길이에 맞게 줄이거나(데스크톱과 같게 할지 먼저 확인 — 웹 = 데스크톱 + α 원칙, 다르게 하면 이유 기록), 베끼기 쪽에서 그런 화살표 둘레까지 글 비키기.
- 공개 칠판 12차 자리에서 「7/8인치」 글이 촉에 안 덮이는 것을 스크린샷으로 확인. 웹 `npm test`·관련 e2e 통과, 데스크톱 쪽을 바꾸면 pytest.

## 주의

- 화면을 고치면 `cd web && npm run build`, 서버 Python을 고치면 공개 서버(감시 PC 5191) 다시 켜기(`tools/start_board_server.bat`).
- 헤드리스로 공개 칠판을 열면 이름 묻는 창이 먼저 뜸 → 입력 칸에 이름 넣고 Enter 뒤 `window.__mb`를 기다림.
