## 1. 도형 판(`web/src/next/palette.jsx`·`mysym.js`) 고치기 — 사용자 요청·검토에서 나온 것

- **메뉴가 판 안을 눌러도 안 닫힘**(재현 확인, 원인 확정): 판 뿌리 `onPointerDown={e => e.stopPropagation()}` 때문에 window 거품 단계 리스너(`pop?.menu` effect)에 신호가 안 감. ⋯를 다시 누르면 닫기가 아니라 다시 열기.
  → 우클릭 메뉴 부품 `FloatMenu`(`ctxmenu.jsx`, 잡기 단계·Esc)로 바꾸고 같은 단추 다시 누르기 = 닫기. 칠판 판 메뉴는 이미 이 방식이라 됨.
- **지우기 확인**: 폴더(안 심볼까지)·심볼 지우기가 즉시·되돌리기 없음 → 칠판 지우기와 같은 앱 안 확인 창(빨간 「지우기」, Enter = 지우기, Esc = 취소). 빈 폴더는 바로.
- **폴더 하나만 파일로 저장**: 폴더 ⋯에 「이 폴더만 내려받기」(파일 이름 = 폴더 이름). 불러오기는 지금 「파일 불러오기」가 폴더 이름대로 넣으니 따로 안 만듦 — 알림에 폴더 이름만.
- **이름 고치는 칸**: 바깥 누르기 = 지금은 취소(고친 글 사라짐) → 저장(칠판 줄과 같게).
- 그 밖 제안(사용자에게 아직 안 물음 — 순서 정해 제안): 심볼 「폴더 옮기기 ▸」, 크게 보기 카드에 「우클릭 = 이름 바꾸기·지우기」, ★ 즐겨찾기를 웹에서 넣고 빼기(지금 서버 파일 읽기만 — 사각형·원이 기본 도형과 겹침, 지운 심볼이 개수에 남는 숨은 버그), 같은 이름 폴더 알림.

## 2. 웹 디자인 규칙 — 사용자 판정 완료(2026-10-28), 웹 전체에 적용

판정 페이지 https://claude.ai/artifact/TtnHM5bYNMnj1A3nd16Myc · 취향 기록 `~/.claude/design-system/projects/easy-cad.md` 「웹 왼쪽 판 규칙 1라운드」.
- **A1**: 코랄 채움 단추 = 판마다 대표 행동 하나(칠판 「＋ 새 칠판」·프레임 「▶ 발표」). 그 밖 단추는 회색 테두리.
- **B1**: 「＋ 새 폴더」·「＋ 새 레이어」 = 머리줄 오른쪽 작은 단추(레이어 판은 지금 아래 → 머리줄로).
- **글·모양 규칙 8개**(모두 채택): ① 새로 만들기 = 「＋ 새 ○○」 ② 같은 일 같은 말 — 지우기(「삭제」 X)·이름 바꾸기(「이름 변경」 X)·내려받기·불러오기, 창이 뜨는 메뉴 항목 끝 「…」 ③ 마우스 올림 = 회색 바탕(지금 위 막대·메뉴는 옅은 코랄) ④ ⋯ = 줄은 올릴 때만, 머리줄은 늘·테두리 없음, 우클릭 = ⋯ 메뉴 ⑤ 메뉴는 한 부품(메뉴 코드 네 벌: ctxmenu·palette pop·layers 자체 메뉴(마우스 벗어나면 닫힘)·칠판 ▾ `MENU_BOX`) ⑥ 되돌릴 수 없는 지우기만 확인 창 ⑦ 이름 고치기 Enter·바깥 = 저장, Esc = 취소 ⑧ 예시 되돌리기 = 따로 보이는 단추(이미 반영).
- 코드 쪽: 코랄 값이 10개 파일에 약 95번 직접(`main.jsx` 34·`chat.jsx` 23…) → CSS 변수 하나 + 단추·메뉴·확인 창 공용 부품 한 파일. 규칙 문서는 repo `docs/`에 쓰고 CLAUDE.md에서 가리킴.
- 끝 기준: 네 판(칠판·도형·프레임·레이어)·위 막대·대화창이 규칙대로 + `npm run e2e` 전부 통과(글 바꾸면 시험의 이름 찾기가 깨질 수 있음 — 시험도 같이).
