# 웹 칠판에서 먼저 한 것을 데스크톱에 맞추기 (그 뒤 5단계 갈아타기)

생성: 2026-10-18 19:05

## 배경
- 웹 칠판(`web/next.html` + `web/src/next/`)은 4단계 이후 사용자 판정을 거치며 기능이 많이 늘었다. 원칙(사용자): 기능은 데스크톱 참고·디자인은 웹에서 풍부하게 → 좋은 건 데스크톱에 역적용.
- 데스크톱은 웹 전용 칸을 지금 **보존만** 한다(`easycad/fileio/document.py` `_WEB_ONLY_KEYS`·`_WEB_ONLY_KEYS_ALL`, 시험 `tests/test_part52_web_extra.py`). 그리지는 않는다.
- 경위 전부: `docs/history/2026-10.md` 끝(「2026-10-18 웹 칠판 4단계 판정 — 사용자 지적 4차」부터 「발표 13차」까지). 계획: `docs/EasyCAD_계획.md` §8 항목61 4) 「데스크톱에 옮길 후보」·4-b).

## 할 일(데스크톱에 옮길 것 — 사용자와 한 번에 범위를 정하고 시작)
1. **표**: 웹 .ecad 칸 `font`·`color`·`pen`·`cell_styles`·`cell_runs`·`row_heights` 그리기, 직접 글자 크기 = 칸이 늘어남(`fitTable` — 그 행·그 열만), 행·열 공통선 끌기(행 높이 새로 — 지금 데스크톱은 열만), 자동 크기 켜고 끄기(소수까지 그대로 고정), 칸 바로 입력(보이지 않는 편집기 미리 포커스 — 한글 첫 글자 함정, pitfalls 참조).
2. **글자 일부 크기**(사용자가 「데스크톱 맞추기 때」로 미룸): .ecad `runs`에 크기 칸이 없음 — 두 앱 같이 형식부터 정할 것.
3. **프레임**: 새 종류 `frame`(rect·name·no(순서)·ratio·magnet:false). 데스크톱은 지금 점선 네모로 열고 저장 때 다시 frame(`_web_extra["type"]`). 진짜로 그리기·이름표·안의 것 같이 움직임·PDF 쪽(프레임 순서)을 옮길지 사용자에게 묻기. 옛 종이틀(`titleblock` plain)은 그대로.
4. 카드 왼쪽 위 라벨(`label.align`)·자동 줄바꿈·`fit_text`, 둥근 모서리(`radius` — 데스크톱은 이미 그림), 고치는 중 「글자」 카드, 복제 되풀이·번호 연속·우클릭 끝, 내보내기 「고른 것 한 쪽에」.
5. 그 다음 = **5단계 갈아타기**(계획서 §8 항목61 5)): tldraw 빼기, 서버에 쌓인 tldraw 칠판을 .ecad로.

## 아직 사용자 판정을 못 받은 것
- 고치는 중 「글자」 카드(드래그한 부분만 굵게·색·형광펜).
- 칸 바로 입력의 실제 윈도우 한글 입력기 첫 글자(시험은 CDP IME 흉내로만 통과).

## 알아둘 것
- 개발 화면 `cd web && npm run dev` → `http://localhost:5190/next.html?board=claude_props`(사용자 칠판 `main`은 보기만). 저장 서버 `python web/server.py --host 127.0.0.1`(5191).
- 확인 기준: 웹 `npm test` 61, 데스크톱 `python -m pytest tests -q` 1418(5분 — 뒤에서 돌리기).
- Playwright(Python) 시험은 스크래치패드 스크립트로: `window.__mb.open(url)`로 .ecad를 넣고(page.route로 가짜 주소), 화면 좌표는 `__mb.getCam()`으로 매번 계산. 미니맵·왼쪽 카드 위를 누르면 화면이 옮겨지니 선택 풀기는 Escape로.
- 긴 패치는 스크래치패드 .py(문자열 바꾸기 + assert). ⚠ 한 줄 코드 중간에 `// 주석`을 끼워 넣으면 그 줄 뒤가 통째로 주석이 되어 빌드가 깨짐(이번 세션 두 번) — 주석은 줄 끝이나 위 줄에.
