## 알아둘 것
- 시험 서버 켜기: 개발 화면 `cd web && npm run dev`(5190), 저장 서버 `PYTHONIOENCODING=utf-8 python web/server.py --host 127.0.0.1`(5191 — 이 PC는 cp949라 한글 출력에서 죽음).
  공동작업 시험 `npm run build` 뒤 `python web/server.py --port 5192 --password test1234 --data <임시 폴더>`.
- 사용자 PC(KBS)에는 `web/node_modules`를 이번에 새로 깔았음(`npm ci`). 시험 칠판 `claude_*`가 `%APPDATA%/EasyCAD/web_boards`에 남아 있음(지워도 됨).
- 확인 기준: 웹 `npm test` 89, 데스크톱 `python -m pytest tests -q` 1432.
- Playwright로 두 사람을 흉내 낼 땐 `browser.newContext()`를 사람마다(쿠키·localStorage 따로). 사용자가 같은 서버 칠판을 쓰는 중이면 시험은 다른 칠판 이름으로.
- 이번 세션 함정(`docs/pitfalls.md` 끝): 한 줄 코드 중간의 `//` 주석이 뒤 코드를 먹음(두 번), 긴 알림이 위 막대를 늘려 칠판을 밈, Pretendard 굵기 미리 불러오기, 발표의 웹 카드 휠, file://의 유튜브 오류 153.
