# 전체 pytest가 가끔 exit 127로 꺼지는 원인 조사

생성: 2026-10-16 14:01

## 무엇이 문제인가

`python -m pytest tests -q`가 결과 줄 없이 exit 127로 꺼질 때가 있다. 2026-10-16 하루 동안 전체 실행 19회 중 3회 발생.
테스트 자체는 꺼지지 않은 실행에서 전부 통과(마지막 1277종). 끝 기준: **전체 실행을 `-q`로 5회 연속 돌려 모두 숫자가 나오고,
원인을 코드·로그로 짚었다**(못 짚으면 패치를 내지 말 것 — 규칙 11-b 부재 확인).

## 지금까지 확인한 것(2026-10-16)

- 꺼진 3회는 모두 `-q`(멈춘 위치 약 70%·30%·마지막 줄 점 45개 — 매번 다름). `-v`로 돌린 8회는 한 번도 안 꺼짐.
- `sys.excepthook` 기록 플러그인(`-p hookcatch`, 스크래치에 있었음 — 아래에 다시 만들 코드)과 `-X faulthandler`를 건 실행은
  4회+2회 전부 통과 — 장치를 걸면 재현이 안 돼 꺼지는 자리 증거가 없다.
- 2026-10-11에 같은 증상을 고친 기록: `docs/history/2026-10.md` "전체 pytest 크래시(exit 127)" — Python GC가 순환 정리 중 위젯
  래퍼의 `__dict__`를 먼저 비우고, C++ 위젯은 살아 Hide 이벤트를 받아 `event()`가 없는 속성을 읽다 예외 → PyQt6가 출력 없이 종료.
  그때는 `_PaletteButton._tooltip_html_fn = None` 클래스 기본값으로 해결.
- 10-16에 새로 생긴 위젯 중 창마다 생기는 것: `easycad/canvas/start_prompt.py` `_StartPrompt`(eventFilter·paintEvent),
  `easycad/canvas/host_check.py` `_CheckCard`(paintEvent, 검사할 때만), AI 패널 `_credit_lbl`·`_CreditWorker`(QThread, 패널을 켤 때마다 시작).
  `_StartPrompt`엔 클래스 기본값을 예방으로 넣었으나 넣은 뒤에도 1회 꺼짐 → 그것만으론 아님(추정).
- 의심 후보(확인 필요): ① `_CreditWorker`가 창 정리 시점에 아직 돌거나 `finished`가 처리 안 된 채 지워짐 ② 다른 Python 재정의
  가상함수(eventFilter·event·paintEvent·dragEnterEvent)가 비워진 `__dict__`를 읽음 ③ 출력 속도(-q/-v)로 GC 시점이 바뀌어 드러나는 기존 문제.

## 방법 제안

1. `-q`로 꺼질 때까지 반복하되, 출력은 그대로 두고 **파일에만** 기록하는 가벼운 장치부터: conftest에 `atexit`/`sys.unraisablehook`
   기록, 각 테스트 시작·끝 이름을 파일에 한 줄씩(flush) — `-v`처럼 화면 출력을 늘리지 않게.
2. 꺼진 직전 테스트 이름을 찾으면 그 파일만 반복(10-11은 `pytest tests/test_part2*.py`가 2/2로 재현됐었다).
3. 후보 ①: `_CreditWorker`를 `_detach_worker`처럼 떼거나 테스트에서 만들지 않게 한 뒤 비교. 후보 ②: Python 재정의 가상함수에서
   읽는 인스턴스 속성 목록을 grep해 클래스 기본값 유무 확인.

예외 기록 플러그인(다시 만들 때):
```python
import sys, traceback, os
LOG = os.path.join(os.path.dirname(__file__), "hook.log")
def _hook(t, v, tb):
    with open(LOG, "a", encoding="utf-8") as f:
        f.write("=== " + "".join(traceback.format_exception(t, v, tb))[-1500:] + "\n")
    sys.__excepthook__(t, v, tb)
sys.excepthook = _hook
```
`PYTHONPATH=<그 폴더> python -m pytest tests -q -p hookcatch`
