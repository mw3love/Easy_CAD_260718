## 할 일(차례대로)
1. **사용자에게 먼저 묻기**: 3단계를 써 본 지적(특히 테두리 14px 끌기 범위, 큐닷 클릭 복제, 알약, 라벨 끌기, 속성 카드 모양). 지적부터 고친다.
2. **3단계 남은 것**: 묶음(그룹) 통째 붙기(데스크톱 `_GroupBindProxy`, `.ecad` bindN_group + 0~1 비율 좌표), 선·화살표 끝에 붙기(바인딩 없는 기하 스냅, `_border_snap_at` 선 부분), 펜 궤적 끝 포트(`_path_endpoint_ports`), 빈 곳에서 바로 그리는 화살표 도구(데스크톱 「화살표」 도구 하나 + 종류는 속성 카드).
3. **4단계 일상 도구**(계획서 §8 항목61 4) 순서): 속성 칸을 다른 도형으로 넓히기(`props.jsx`가 씨앗), 스타일 복사·붙여넣기, 내 심볼 팔레트(`symbol_library.json` 공유), 번호표·표, 레이어, 미니맵, PNG·PDF 내보내기, 대화창 카드 붙이기.

## 데스크톱에 옮길 후보(웹에서 먼저 한 것)
- 화살표 종류를 바꿀 때 라벨 전부·t·off를 지킴(데스크톱 `_make_swapped_arrow`는 첫 라벨 글자만).
- 알약을 클릭만 했을 때는 자동 길을 끄지 않음(데스크톱은 클릭만 해도 끔).

## 알아둘 것(함정)
- 개발 화면 `cd web && npm run dev` → `http://localhost:5190/next.html`. 시험용 칠판은 `?board=claude_test`(사용자 칠판 `main`을 안 덮음). 저장 서버 `python web/server.py --host 127.0.0.1`(5191).
- `window.__mb.model`은 값이라 바로 뒤 읽으면 옛것일 수 있음 — 잠깐 기다린 뒤 읽기. 큰 시험 문서: `python tools/make_perf_doc.py --shapes 3000 --arrows 1500`(4500개에서 포트점 예고 한 프레임 안).
- Bash heredoc으로 긴 편집 스크립트를 넘기면 셸이 따옴표를 잘못 읽는 일이 있음 — 스크래치패드에 .py로 써서 돌리기.
- `symbols.js`의 JSON 불러오기는 `with { type: 'json' }`(node 시험에서 필요, vite도 됨).
