# 데스크톱 손맛 마지막 — 위 막대 다각형 끌기 + 휠 클릭 결정

생성: 2026-10-23 01:00

## 배경
「데스크톱 = 웹 + 추가 기능」(CLAUDE.md 목표). 10-22에 웹 `keys.js` 기준 손맛 묶음과 메모 기능을 거의 다 맞춤(`docs/history/2026-10.md` 끝 「손맛 1~4차」·「메모 남은 3가지」).

## 할 일
- **위 막대 다각형 버튼 끌기** — 웹 `Editor.jsx` `startToolDrag('polygon')`: 끌어 놓으면 놓은 자리에 첫 선분(화면 120px 가로)을 놓고 다각형 도구로 이어 찍기(Enter·처음 점 = 끝).
  데스크톱은 `_ToolbarDragFilter`(host_widgets) + `_palette_drag_begin` 키 `tb:<종류>`(host_fileio `_build_toolbar_item`)에 다각형만 빠짐 — 다각형 도구의 클릭 배치 상태(`core_view` `_place`)에 첫 두 점을 넣는 길을 찾아야 함.
  펜은 웹도 끌기 없음. 표제란·보드·이미지는 데스크톱 전용이라 웹 기준 없음 — 넣을지 같이 판단.
- **휠 클릭 결정(사용자에게 물을 것)** — 웹: 휠 클릭 끌기 = 화면 이동. 데스크톱: 휠 클릭 끌기 = 창 이동(`_win_drag_start`). 바꾸면 창 옮기기 수단이 사라지니 선택창으로 물음.
