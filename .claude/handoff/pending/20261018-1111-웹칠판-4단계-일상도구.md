# 웹 칠판 4단계 — 일상 도구(속성 카드를 다른 도형으로 넓히기부터)

생성: 2026-10-18 11:11

## 배경
- 웹 칠판 직접 만들기(§8 항목61 「바뀐 결정」) 1~3단계 끝. 3단계 화살표의 사용자 손맛 확인까지 2026-10-18에 마침(실조건검증) — 상세 `docs/history/2026-10.md` 끝 「2026-10-18」 세 항목.
- 2026-10-18에 정해진 것(4단계에서 그대로 따를 규칙):
  - **선택 표시** = 데스크톱과 같음: 하나 선택·화살표 = 화면 1.6px 가운데 선, 여러 개 중 닫힌 도형 = 바깥 띠(선 굵기 + 3 칠판 단위), 범위 미리보기 띠(왼→오 파랑 `70,130,220`·오→왼 초록 `90,190,90`, 테두리는 `geom.js strokeOutline` 계산 — 마스크 금지).
  - **값이 섞였을 때**(사용자 선택, 두 앱 공통): 숫자 칸 = 「1~3px」 + ±는 각자 더하기, 고르는 칸 = 아무것도 안 켬(데스크톱 「혼합」), 데스크톱 두께 프리셋 = 전부 그 값. 웹 `props.jsx` `Stepper({values, onStep})`·`ArrowProps({arrows})`가 씨앗.
  - **어두운 화면**은 앱이 직접(`next.html` CSS 변수 `--mb-*`, 데스크톱 `_dark_palette` 값). 칠판 검정 잉크는 `render.jsx ink()`가 흰색으로 보이게(파일 색은 그대로). Dark Reader 막는 메타 지우지 말 것.
  - 새 도형·화살표 기본 굵기 1px(데스크톱 `_DEFAULT_WIDTH`).
- 사용자 원칙: 기능은 데스크톱 참고, 디자인은 웹에서 더 풍부하게 해 보고 좋은 건 데스크톱에 역적용.

## 할 일(차례대로, 계획서 §8 항목61 4) 순서)
1. **속성 카드를 다른 도형으로 넓히기** — 지금은 화살표만(`props.jsx ArrowProps`). 상자·원·심볼·글·선·다각형·펜: 선 색·굵기·선 모양·채움, 글 크기·색. 데스크톱 속성 카드(`host_style._refresh_properties`, 위 「값이 섞였을 때」 규칙 포함)와 같은 항목·같은 자리(오른쪽 위, 폭 192). 섞어 고르면 공통 항목만. 끝 기준: 데스크톱과 나란히 놓고 같은 선택에서 같은 칸이 같은 값으로 보임 + 고치면 `.ecad` 왕복 유지.
2. 스타일 복사·붙여넣기, 내 심볼 팔레트(`symbol_library.json` 공유), 번호표·표, 레이어, 미니맵, PNG·PDF 내보내기, 대화창 카드 붙이기.
3. 제자리 우클릭 메뉴(우클릭 끌기 = 화면 이동은 됨).

## 데스크톱에 옮길 후보(웹에서 먼저 한 것)
- 화살표 종류를 바꿀 때 라벨 전부·t·off를 지킴(데스크톱 `_make_swapped_arrow`는 첫 라벨 글자만).
- 알약을 클릭만 했을 때는 자동 길을 끄지 않음(데스크톱은 클릭만 해도 끔).
- ①버튼 줄(계획서 §8 항목61 목록)은 4단계 속성 카드 뒤에 한꺼번에.

## 남은 관찰(고칠지는 사용자 판단)
- 출구 법선이 목표 반대쪽이면 직각 길이 짧게 나갔다 같은 줄에서 되돌아감(두 앱 같은 길 찾기). 알약 끌기 사선은 고쳤음(`1f04919`).
- 묶음 복제 때 붙은 화살표의 `bindN_group`을 새 묶음으로 바꾸기(데스크톱은 함), 화살표 도구의 클릭으로 꺾는 점 찍기 — 안 함.
- `main` 칠판에 예전 버그로 사선이 된 화살표가 남아 있음(사용자가 다시 그리면 됨).

## 알아둘 것(함정)
- 개발 화면 `cd web && npm run dev` → `http://localhost:5190/next.html`. 시험용 칠판 `?board=claude_test`, Claude 자체 확인은 `?board=claude_sel`(사용자 칠판 `main`을 안 덮음). 저장 서버 `python web/server.py --host 127.0.0.1`(5191).
- 사용자 스크린샷 비교 전 강제 다크 여부부터(이번에 Dark Reader 때문에 색·두께 비교가 여러 번 헛돎 — `docs/pitfalls.md`).
- 같은 증상 재보고면 사용자 조작 순서를 브라우저에서 그대로 재현해 어느 단계에서 생기는지부터(사선 건, wiki 기록).
- 대조 시험: 데스크톱 규칙을 고치면 `tools/export_connect_cases.py`·`export_arrow_cases.py` 다시 돌리고 `npm test`(웹 54, 데스크톱 pytest 1413).
- Bash heredoc 긴 편집은 셸 따옴표 문제 — 스크래치패드에 .py로 써서 돌리기. 한 줄짜리 JSX 줄 끝에 주석을 붙이면 뒤 코드가 주석이 됨(이번에 빌드 깨짐).
- Playwright 스크린샷은 레포 안 `.playwright-mcp/`에만 저장 가능(무시 대상).
