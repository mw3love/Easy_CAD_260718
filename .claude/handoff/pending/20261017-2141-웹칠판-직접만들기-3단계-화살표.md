## 할 일(3단계 끝 기준 — 계획서 그대로)
직각·직선·곡선 화살표, 큐닷(선택 상자 네 변 24px 밖 — **클릭 = 도형 복제+연결**, 끌기 = 화살표, 데스크톱 `_qc_create`), 미선택 상자 포트점 예고, 끝점 손잡이(다시 붙이기·떼기)·알약(구간 평행 이동)·경유지(`route_hints` 1개, 데스크톱 `_route_with_hints`),
라벨 여러 개(더블클릭 추가·t/off 길 따라감, 선 끊김은 render.jsx에 이미 있음), 화살촉 4가지(끝·시작·양쪽·없음)·크기 배율, 색·굵기·점선·모서리 반경, 붙는 대상 전부(상자·원·심볼·이미지·표·닫힌 다각형·독립 글), 실제 외곽선(원·마름모 — 데스크톱 `_nearest_border`/`_shape_ports`), 직선 모드(routing 'straight').
끝: 데스크톱 대조 시험(붙기·외곽선·라벨 위치) + 실제 마우스 자체확인 + 사용자 손맛 합격.

## 재활용할 것(옛 tldraw 쪽에 이미 만든 데스크톱 규칙)
- `web/src/cad.jsx`(tldraw용): `snapAt`(포트 18px → 테두리 14px → 안 붙음 = 데스크톱 `_border_snap_at`), 비율 부착점 nx·ny, 포트점 예고, 끝점 다시 붙이기, 손잡이 곁 예고점 끄기 — 로직을 새 칠판(Editor.jsx)으로 옮길 것. `.ecad`는 부착점을 도형 로컬 좌표 `bindN_pt`로 저장(웹 모델에선 그대로 둠).
- `web/src/route.js` = 데스크톱 `_route_ortho` 이식(그대로 씀). 최소 스텁 = 화살촉 + 모서리 반경 + 4.
- 데스크톱 참고 위치: `easycad/canvas/core_shapes.py` `_ArrowItem`(3427~, 곡선 베지어 ctrl1/ctrl2·bend 핸들) / `_PolyArrowItem`(4197~, routing·curve_r·route_hints·라벨 `add_label_at_t`·`_snap_label_off`) / `core_view.py` `_border_snap_at`(1721)·`_hover_port_at`(2281)·`_qc_create`.

## 알아둘 것(함정)
- 시험 좌표: 좌상 「도형」 카드(화면 12~162, 12~90)가 칠판을 덮음 — 그 자리를 누르는 시험은 카드를 누른다. 화면 밖 좌표 클릭은 아무 일도 안 됨.
- `window.__mb.ed`는 getter(늘 최신 편집기), `debugHandle(p)`·`debugState()` 시험용.
- 개발 화면: 5190에 지난 vite가 떠 있으면 새 vite가 5191로 밀려 저장 서버와 겹친다(`docs/pitfalls.md`). 서버 `python web/server.py --host 127.0.0.1`(5191), 새 칠판 저장 `/api/doc/<이름>`.
- Bash heredoc 안 파이썬 문자열 `\\n`이 진짜 줄바꿈이 됨 — 코드 고치기는 Edit/Write로.
- 샘플: `web/public/samples/all_types.ecad`(모든 종류, 기준 = `tools/make_all_types_ecad.py`), `web/public/_local/`(login_flow·1TV·uhd06 — git 제외).
